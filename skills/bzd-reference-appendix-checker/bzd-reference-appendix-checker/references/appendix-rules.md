# 附录内容与长度检查规则

## 长度判断

1. 先读取当届官方规则或赛区规定中的页数与材料要求。
2. 分别统计正文和附录页数，说明统计口径。
3. 没有官方上限时，将“附录不超过正文页数约 1/2”作为默认精简性建议：
   - 不超过约 1/2：通常可接受，仍需检查是否有无关内容；
   - 超过约 1/2：标记为“偏长”，逐项核查必要性；
   - 明显超过正文：重点检查大段重复、原始赛题数据、调试日志和低价值中间结果。
4. 比例只用于编辑建议，不用于宣称取消资格。完整源程序、必要复现数据和官方要求材料不能仅为压缩页数而删除。

## 应保留内容

- 支撑材料文件列表；
- 实际使用的软件环境、库、求解器和运行顺序；
- 全部必要且可运行的源程序或明确的无程序声明；
- 必要的详细推导、完整结果、长表和灵敏度分析；
- 自主收集数据的字段、来源和补充说明。

## 应精简内容

- 与正文完全重复的图表、公式和说明；
- 赛题已经提供且无需再次提交的原始数据；
- 无关测试代码、废弃版本和调试日志；
- 未被正文使用的大量中间输出；
- 《AI工具使用详情.pdf》全文（该文件应独立提交）；
- 通过空行、超大字号或低密度排版人为增加的页数。

## 一致性

附录文件名必须与实际材料一致；代码的参数、公式、约束、输入输出和结果必须与正文一致。未实际运行程序时只能报告“未验证”。
