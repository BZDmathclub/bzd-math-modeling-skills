# CUMCM A—E 题题意翻译信号库

## 使用顺序与边界

先逐句读取当前题目，再按题号选择下表。历史规律只用于追问“这句话是否包含类似作用”，不得补写题面没有的条件。新题明确含义优先；歧义应列出多种解释及其后果。2025 E 题缺少命题人评阅材料，相关内容属于题目结构归纳。

## 分题型稳定内核与隐藏信号

| 题型 | 稳定内核 | 题干信号应翻译成什么 |
|---|---|---|
| A | 工程机理—数值仿真—约束优化 | 尺寸/角度/速度/范围→硬约束；完整覆盖/碰撞/遮挡→真实几何判据；分段运动→状态切换；多主体→协同与共享资源；精度要求→步长、容差和收敛证据 |
| B | 有限观测—参数识别—方案决策 | “只能获得/不得使用”→信息边界；比例/角度/频谱/网格→特殊数据空间；可靠/重叠/干涉→定量定义；多角度/多批次→一致性与可识别性；推断结果→具体实验或决策 |
| C | 特殊数据结构—现实机制—可验证决策 | 未发生业务导致的0→结构性零；总和100%→成分数据；隔日失效→非对称损失；若干期至少一次→跨期窗口；同一对象多次记录→重复测量；附件方案→可复算硬约束 |
| D | 密集规则—动态状态—可执行方案 | 先后次序→业务优先级；容量/时窗→资源约束；异常到达→重规划；分叉/汇合→动态状态更新；“建立一般模型”→参数化表达；结果文件→逐时逐对象操作表 |
| E | 数据语义—可信验证—业务闭环 | 字段名→物理/业务定义；时间戳→预测时可用信息；同主体多记录→分组划分；高维/连续/不平衡→结构适配；识别/预测→生产、监测、控制或训练动作 |

## 跨问联动的典型结构

- A：基础几何/机理 → 给定参数仿真 → 增加耦合或空间条件 → 优化 → 多主体/极限工况验证。
- B：数据与观测审计 → 参数估计/反演 → 可靠性 → 实验、测量或生产决策。
- C：关系/指标 → 基础预测、分类或决策 → 增加不确定性与细粒度对象 → 求解后审计。
- D：静态规则 → 一般模型 → 动态事件 → 扰动重规划 → 操作方案。
- E：数据认识 → 标签/特征 → 预测或识别 → 决策 → 部署条件验证。

只有当前题目真实支持时才画上述链；平行问题必须画成平行分支。

## 高风险漏读提示

- A：对象有面积或体积却被误读为点/线；碰撞、遮蔽只检查中心；坐标和角度方向不统一。
- B：偷用禁止信息；拟合好却参数不可识别；关键术语没有可执行定义。
- C：把缺失、结构性零和真实零混为一谈；随机拆分时间/重复样本；后一问没有复用前问结果。
- D：把优先级当普通加权目标；把动态系统静态化；只提交指标而无具体方案。
- E：字段概念混淆；未来信息或同主体泄漏；训练集效果冒充部署效果。

## 结构化标签

每条内部记录可标注：`problem_type`、`signal`、`explicit_or_implied`、`implication`、`upstream`、`downstream`、`omission_risk`、`required_evidence`、`evidence_year`、`confidence`、`hard_rule`。
