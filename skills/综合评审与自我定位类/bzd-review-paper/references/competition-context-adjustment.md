# CUMCM Competition Context Adjustment

本规则只用于高教社杯全国大学生数学建模竞赛的奖项竞争力预测。它不修改论文质量原始判断，不代表官方名额分配或确定获奖结果。

## 1. 必须输入

对 CUMCM 数值评审，除完整赛题和论文外，必须取得：

- 所属赛区；
- 学校全称；
- 指导教师姓名；
- 参赛组别：`本科组` 或 `高职高专组`。

缺少任一项时，可以完成论文质量评分，但相关竞争修正只能标记为 `无法计算/待补充`，不得猜测学校、教师或组别。

## 2. 数据文件

- `data/school_awards_2021_2026.csv`：1127 所学校的 2021—2025 国奖、2026 预测、数模强校、最高频指导教师和教师占比。
- `data/region_public_statistics.csv`：31 个赛区公开的参赛规模、推送国奖、获奖率、学校数和强校数。
- `data/region_difficulty_scores.csv`：本科/高职高专组的国奖和省奖难度排名与 0—100 难度得分。

只根据数据文件的实际字段判断。学校匹配应先使用去除首尾空格后的精确名称，再使用统一全半角括号与空白的规范化名称。模糊匹配只能作为候选提示，未经用户确认不得应用学校修正。

## 3. 双轨分数

始终保留：

1. `论文质量原始得分`：评分细则逐项所得分数；
2. `格式质量系数`；
3. `论文质量最终得分 = 原始得分 × 格式质量系数`；
4. `省奖竞争修正分`；
5. `国奖竞争修正分`。

学校、赛区、教师和组别不得回写或伪装成论文质量扣分。所有修正必须逐项展示依据、增减值、封顶和不确定性。

## 4. 赛区修正

从 `region_difficulty_scores.csv` 选择与组别、奖项层级对应的难度得分 `D`：

- 本科国奖：`undergraduate_national_difficulty`；
- 高职高专国奖：`vocational_national_difficulty`；
- 本科省奖：`undergraduate_provincial_difficulty`；
- 高职高专省奖：`vocational_provincial_difficulty`。

使用透明、分层限幅的分数修正：

`国奖赛区修正值 = clamp((50 - D) / 50 × 15, -15, +15)`

`省奖赛区修正值 = clamp((50 - D) / 50 × 10, -10, +10)`

难度高于 50 时，同质量论文的竞争修正分下降；难度低于 50 时上升。国奖赛区修正最多 ±15 分，省奖赛区修正最多 ±10 分。国奖采用更大幅度，是为了体现强赛区省一等奖论文质量可能高于弱赛区部分国奖论文的实际竞争差异。修正只作用于奖项竞争分，不改变论文质量最终得分。

省奖分析同时列出 `region_public_statistics.csv` 的参赛队数、相应组别学校/队伍数、获奖率和数模强校数量。**本科组**可以把 985、211 高校数量作为竞争环境证据；**高职高专组不得使用 985、211 数量进行修正或评价**。

本科与高职高专必须分开计算。已有组别专属难度得分时，不再额外应用“本科难度约为高职两倍”的二次加成，避免重复修正。只有组别专属难度缺失时，才可把“高职高专获奖难度约为本科一半”作为低置信度定性提示，不得凭此把分数直接乘二。

## 5. 学校修正

### 学校在表内

- 输出五年国奖合计、2026 国奖预测、是否数模强校、最高频教师、教师频率及是否超过 30%。
- `是否为数模强项=是` 时，国奖竞争修正值增加 `+1.5`；否则为 `0`。这只表示历史组织与训练优势，不是论文加分。
- 不根据 985/211 身份直接给学校加分；相关数量只用于解释本科赛区竞争环境。

### 学校不在表内

- 明确输出：`该学校未出现在2021—2025国奖学校统计表中。`
- 国奖概率上限设为 `6.81%`；表述为经验先验上限，不是个体确定概率。
- 奖项预测最高只到 `省一等奖`。
- 国奖竞争修正分不得达到国奖阈值：最终封顶 `74.9`；论文质量分和省奖竞争修正分仍照常展示。
- 不得把“未在表中”解释为学校没有能力或学生一定无法获奖。

## 6. 指导教师集中度修正

仅当学校在表内且 `老师出现频率是否大于30%=是` 时应用：

- 输入指导教师与 `top_advisor` 规范化后相同：国奖竞争修正 `+0.5`，表示历史指导连续性；
- 不同：国奖竞争修正为负，按 `-min(4.0, 1.5 + 5 × (frequency - 0.30))` 计算；
- 未提供教师或姓名无法可靠匹配：不做数值修正，降低预测置信度，并说明该学校国奖历史集中于特定教师。

教师集中度不影响省奖竞争修正分。不得把非高频教师学生表述为“不可能获奖”。

## 7. 计算顺序

令 `S` 为论文质量最终得分：

1. `省奖竞争修正分 = clamp(S + 省奖赛区修正, 0, 90)`；
2. `国奖竞争修正分 = clamp(S + 国奖赛区修正 + 学校修正 + 教师修正, 0, 90)`；
3. 学校不在表内时，再令 `国奖竞争修正分 = min(国奖竞争修正分, 74.9)`；
4. 论文质量分、两个竞争分和每项修正必须同时输出，不得只显示修正后的一个分数。

优先运行 `scripts/competition_context.py`，避免手算错误。

## 8. 置信度

- 完整赛题、完整论文、赛区、学校、教师、组别齐全且学校精确匹配：默认 `中等`；
- 教师缺失、学校需人工确认或数据年份已过期：降为 `中低`；
- 学校不在表、论文不完整、赛区/组别缺失：`低`；
- 不得因数据字段齐全而声称高置信度，因为赛区难度和学校历史只是经验先验。

## 9. 必须提示的创新盲区

每份 CUMCM 报告必须说明：每年存在少量论文因解题路径非常新颖、超出常见评审框架而获得国奖。AI 评审主要依据可识别的任务完成度、数学正确性、验证证据和历史评阅规律，可能低估评委未曾预期的真正创新路径；目前无法可靠消除该盲区。

## 10. 时间与更新

所有赛区难度、学校历史和教师集中度均为历史数据。报告必须列出数据适用年份，并提醒下一年度参赛规模、名额、学校训练体系和教师团队可能变化。
