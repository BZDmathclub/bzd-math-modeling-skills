## 二、语言模板化检查（权重60%）

### 2.1 高频连接词检测（直接采用Humanizer-zh）

**Humanizer-zh AI常见高频连接词列表**：

| 连接词 | AI高频程度 | 数模正常频率 | 高风险阈值 | 检查方法 |
|---|---|---|---|---|
| 综合上述/综上所述 | ⭐⭐⭐⭐⭐ | 低 | >3次 | 每章末尾总结时合理；多于此即为套话 |
| 进一步 | ⭐⭐⭐⭐ | 低 | 密度>15% | "进一步在p±0.01扰动"有数据✓；"进一步验证准确性"无数据✗ |
| 此外 | ⭐⭐⭐ | 中 | 连续>2次 | 列举多个问题时合理；连续出现即为套话 |
| 与此同时 | ⭐⭐⭐ | 低 | >2次 | 平行描述两个约束时合理；频繁使用为套话 |
| 值得注意的是 | ⭐⭐⭐ | 低 | >1次 | 强调关键数值时合理；超过1次为套话 |
| 可以看出 | ⭐⭐⭐⭐ | 中 | 无具体内容时 | "可以看出，当p>0.45m时..."✓；"可以看出结果良好"✗ |
| 一般来说 | ⭐⭐⭐ | 低 | 出现≥1次 | 数模中基本不用，出现即为AI风格 |
| 由此可见 | ⭐⭐⭐ | 中 | 密度>10% | 从数值推导结论时合理；过频即为套话 |
| 不仅...而且 | ⭐⭐⭐ | 低 | 连续>1次 | 列举关联条件时合理；连续使用为套话 |
| 当然 | ⭐⭐ | 低 | 任何出现 | 科学论文中应避免，出现即为非正式 |

**高频连接词密度计算**：
```
高频连接词密度 = (高频词总出现次数) / (全文总句数)

判定标准：
  <15% → 🟢低风险（正常）
  15-20% → 🟡中低风险（注意）
  20-25% → 🟠中风险（需要改进）
  >25% → 🔴高风险（严重套话）
```

**相同词重复间隔检查**：
```
重复间隔 = 某个高频词前后两次出现的页数差

如"综上所述"出现3次，分别在P3、P8、P15
  间隔1 = 8-3 = 5页
  间隔2 = 15-8 = 7页
  
判定标准：
  间隔>5页 → 正常，不同位置不同用途
  间隔<5页 → 套话风险，可能机械重复
```

### 2.2 排比与同构句式

**排比句检查**：
```
定义：三项或以上，结构相似或并列的句子

❌ AI常见模式（风险高）：
"模型的优点是准确性高、鲁棒性强、计算速度快"
"该方法可以应用于交通、医疗、金融等多个领域"
→ 排比后全是抽象修饰词，无具体数据

✓ 数模正常模式（风险低）：
"满足以下约束条件：(1) 螺距p≥0.30m，(2) 转向半径R<4.5m，(3) 速度v≤2m/s"
"三问的联动关系：Q1提供初值 → Q2推导停止条件 → Q3使用R值约束"
→ 排比后都有量化数据或明确的本题对象
```

**同构句式检查**：
```
定义："动词+宾语"结构完全相同，连续出现多次

❌ AI常见（风险高）：
"采用方法A进行建模，采用方法B进行求解，采用方法C进行验证"
→ 三个句子结构完全相同，机械重复

✓ 数模正常（风险低）：
"利用等距螺线(1.1节)建立位置约束，利用SAT算法(2.1节)建立碰撞检测，
利用二分法(3.1节)建立搜索框架"
→ 虽然结构相似，但标注了章节号、有具体对象、约束条件清晰
```

**排比和同构句式风险判定**：
```
有排比/同构句 → 检查内容：
  • 排比/同构后是否都有量化数据或具体对象？
  • 是否标注了章节号/约束条件？
  
有 → 🟢低风险（正常学术表达）
无 → 🔴高风险（AI套话）
```

### 2.3 被动句与拔高词

**被动句检查**：
```
正常范围：全文被动句占比 10-20%
AI风格：被动句占比 >30%

❌ AI常见被动句：
"该模型被选择用于..."
"该参数被设定为..."
"结果被验证为具有高准确性"

✓ 数模正常主动句：
"选择SAT模型，因为本题的碰撞对象是凸多边形"
"设定参数p=0.55m，来自赛题"
"验证结果：精度为10^-12 m，超过需求"
```

**拔高词检查**（来自Humanizer-zh的拔高词库）：
```
AI常见拔高词：
  具有重要意义、显著提高、大幅提升、显著优势、
  奠定坚实基础、彰显巨大价值、具有较强的XX性、
  有效解决、完美实现、取得突出成果

检查规则：拔高词后是否有量化的"高"的证据？

❌ 高风险（拔高词后无数据）：
"结果具有较强的鲁棒性"
"模型具有很好的适用性"
"该方法显著提高了精度"

✓ 低风险（拔高词有量化证据）：
"结果具有较强的鲁棒性：参数±10%变化时，结果偏差<0.1%"
"模型的适用性范围为螺距[0.30-0.56]m，超出该范围需要分段处理"
"该方法的精度提升：相比线性搜索，速度提升3倍"
```

### 2.4 其他四维评分标准

#### 结构与论证（权重12%）

| 评分段 | 特征 |
|---|---|
| 90-100 | 章节齐全，逻辑递进，主张与证据完全对应 |
| 70-89 | 章节齐全，逻辑基本清晰，多数段落主证对应 |
| 50-69 | 章节齐全但部分冗余，段落结构像清单 |
| 30-49 | 章节缺失或层次混乱，主张与证据不对应多处 |
| 0-29 | 结构混乱，逻辑断层 |

#### 建模专属性（权重15%）

| 评分段 | 特征 |
|---|---|
| 90-100 | 每个模型都完全映射到本题的对象、变量、约束、单位、数据 |
| 70-89 | 大多数模型有明确的本题映射 |
| 50-69 | 部分模型映射不清，有通用模板感 |
| 30-49 | 多个模型像百科原理，未见本题特色 |
| 0-29 | 模型与本题脱节，完全是通用建模 |

#### 求解与验证（权重10%）

| 评分段 | 特征 |
|---|---|
| 90-100 | 算法步骤完整、参数有来源、代码可复现、检验指标与模型匹配 |
| 70-89 | 算法基本清晰、参数说明、结果可追踪、有检验 |
| 50-69 | 只写"导入软件求解"或缺参数、初值、终止条件 |
| 30-49 | 求解过程模糊，检验缺失或指标不匹配 |
| 0-29 | 无法复现，无检验 |

#### 来源与一致性（权重3%）

| 评分段 | 特征 |
|---|---|
| 90-100 | 引用、数据来源、代码、图表、术语全部一致，无幻觉 |
| 70-89 | 大多数引用和数据来源清晰，符号表与正文对应 |
| 50-69 | 部分引用不存在或数据来源模糊 |
| 30-49 | 多处数值或术语冲突，参考文献格式不规范 |
| 0-29 | 引用虚假、数据来源不明、符号混乱 |

- ✓ 层次分析法(AHP)
- ✓ 熵权法

#### 自定义模型（但有明确的问题驱动）
- ✓ 基于几何约束推导的特殊曲线

### 3.2 模型复杂度vs收益评估

**对每个模型问三个问题**：

| 问题 | 目的 | 低风险回答 | 高风险回答 |
|---|---|---|---|
| **Q1：这个模型的复杂度是多少？** | 判断是否理解模型复杂度 | "时间O(log n)，代码10行，流程3步" | "该算法高效" |
| **Q2：能否用更简单的方法？为什么没用？** | 判断是否考虑过替代方案 | "线性搜索O(n)需50次迭代；二分O(log n)只需4次；其他方法更复杂" | "该算法是最优选择" |
| **Q3：复杂度提升的收益有多大？** | 判断是否值得用复杂方法 | "精度提升10%，计算量翻倍，综合收益正" | "模型准确度更高" |

**复杂度评估表**：

| 模型 | O(X)复杂度 | 能否更简单 | 收益是否值 | 判定 |
|---|---|---|---|---|
| Q1等距螺线 | O(1) | 无 | N/A | ✓最简 |
| Q2 SAT | O(n) | 有(蛮力O(n²)) | 收益明显(15倍) | ✓合理 |
| Q3二分搜索 | O(log n) | 有(线性O(n)) | 收益明显(12倍) | ✓合理 |
| Q4两段圆弧 | 解析求解 | 有(Bezier数值) | 收益明显(代码简洁) | ✓合理 |

### 3.3 华而不实的识别（五大特征）

**特征1：模型名称复杂，但实现细节不清楚**
```
❌ "采用改进的遗传算法"
   问：改进了什么？→ 无法回答

✓ "采用标准遗传算法，交叉概率Pc=0.8，变异概率Pm=0.01，世代数500"
   问：参数来自何处？→ 可以回答（文献推荐值）
```

**特征2：声称模型效果好，但没有对比基线**
```
❌ "该模型准确性高、鲁棒性强"
   问：与谁比？→ 与谁都没比

✓ "SAT方法相比蛮力搜索，速度提升15倍；相比GJK，代码简洁50%"
   问：与谁比？→ 有明确基线对比
```

**特征3：引入过多超参数调优，但目的不明确**
```
❌ "通过网格搜索调优了5个超参数，最终精度XX%"
   问：为什么要调这5个？→ 无说明

✓ "参数Pc=0.8, Pm=0.01遵循文献[X]的推荐值，无需额外调优，保证可复现性"
   问：参数来自何处？→ 有明确来源
```

**特征4：模型通用化声明，但缺乏"本题特例化"的论证**
```
❌ "该模型可广泛应用于各种工程优化问题"
   问：本题之外的应用范围？→ 模糊的通用化

✓ "该搜索框架在螺距范围[0.30-0.56]m内有效；若扩大至[0-1]m应考虑分段搜索"
   问：应用边界在哪？→ 明确限定
```

**特征5：问题个数与模型个数不匹配，存在冗余**
```
❌ 5个问题，却建立了7-8个不同的模型，很少复用

✓ 5个问题，用2-3个核心模型的变体，问问之间有逻辑联系
```

**华而不实判定表**：

| 特征 | 该论文有无此特征 | 位置 | 严重程度 |
|---|---|---|---|
| 1. 模型名复杂实现不透明 | 无 | - | - |
| 2. 效果声称无基线 | 无 | - | - |
| 3. 超参数调优过度 | 无 | - | - |
| 4. 通用化无边界 | 1处 | P24评价 | 🟡轻 |
| 5. 模型数过多 | 否 | - | - |

**综合判定**：0-1项 → 低风险；2项 → 中风险；3项以上 → 高风险

### 3.4 模型选择"三问法"

对每个模型，逐一回答三个问题：

**【第1问】本问的问题性质是什么？**
```
考察：是否明确了该问的目标和约束

✓ 好回答："问题1要求在螺距约束p=0.55m下，计算224把手的位置"
✗ 坏回答："问题1需要建立位置模型"
```

**【第2问】本问有什么特殊的数据或几何特征？**
```
考察：是否说明了为什么这个模型适合本问

✓ 好回答："本问的碰撞对象都是凸多边形(磁盘、板)，数量≤3，
          所以选SAT算法，时间复杂度仅O(n)"
✗ 坏回答："选择SAT因为它精度高、速度快"（通用套话，未指本题）
```

**【第3问】这个模型是数模常规还是AI高大上？**
```
考察：是否解释了为什么不用其他替代方案

✓ 好回答："二分搜索O(log n)，相比线性搜索O(n)快；
          相比三叉搜索O(log₃n)，代码简洁；
          相比贪心/遗传等启发式，二分保证最优解"
✗ 坏回答："采用改进的粒子群优化"（不说为什么不用二分搜索）
```

**三问法综合判定**：
```
三问都能清晰回答 → ✓低风险
任何一问无法清晰回答 → 🟡中等风险 → 🔴高风险
```

## 四、第一层和第二层的综合评分

**最终AI风险分** = (第一层得分 + 第二层得分) / 2

| 最终分数 | 风险等级 | 特征 | 建议 |
|---|---|---|---|
| 0-20 | 🟢低风险 | 语言规范、建模清晰、模型合理 | 可直接接收 |
| 21-35 | 🟡中低风险 | 语言有套话、建模基本清晰 | 可接收，建议补充改进 |
| 36-54 | 🟠中风险 | 语言和建模均有问题 | 需要深度检查 |
| 55-74 | 🔴中高风险 | 多维度问题，可能涉及AI | 强烈建议拒稿或强制改稿 |
| 75-100 | ⛔高风险 | 确认有AI拼装迹象 | 建议拒稿 |

## 五、检查清单（逐项执行）

- [ ] 自定义模型的话，检查是否有明确的问题驱动

### 三问法审查清单（第二层）

对每个模型：
- [ ] 第1问：问题性质是否明确？（目标、约束清晰）
- [ ] 第2问：本题数据特征是否明确？（为什么这个模型适合）
- [ ] 第3问：替代方案论证是否清晰？（为什么不用其他方法）

## 六、特殊场景处理

### 场景1：赛题缺失的情况

当无法获得原始赛题时，建模专属性和模型常用性的判断置信度下降。

处理方式：
- 从论文的"问题重述"反推赛题约束
- 对模型常用性的判断改为"是否为常见竞赛模型"
- 将置信度从"高"降为"中"

### 场景2：代码和中间结果缺失

当无法获得代码和中间结果时，求解与验证、参数溯源的判断置信度下降。

处理方式：
- 基于论文的数值结果反推参数来源
- 检查论文中给出的图表是否可追踪
- 将置信度从"高"降为"中"

### 场景3：跨问依赖不明确

当问间对接不清晰时，建模专属性判断受影响。

处理方式：
- 检查论文中是否有"基于问i的结果，进行问i+1"的过渡句
- 查看是否有明确的"数据流"说明（前问的哪个输出进入后问的哪个变量）
- 标记为"中等风险"

## 七、修改建议优先级

| 优先级 | 类型 | 例子 | 修改方向 |
|---|---|---|---|
| P1（必改） | 参数来源不明 | "取值X参数为Y" | 补充"来自赛题""来自问i""来自约束YYY" |
| P1 | 模型选择无论证 | "采用XX模型" | 补充"因为本题的XX特性，所以选YY" |
| P1 | 拔高词无据 | "结果准确性高" | 改为"精度为10^-X m，偏差<Y%" |
| P2（应改） | 连接词过密 | 连接词>20% | 删除或补充数据，化套话为实质 |
| P2 | 参考文献缺少同领域近期论文 | 共9项，无2020后论文 | 补充3-5篇同领域论文 |
| P3（可选） | 问间对接不够明确 | "基于前问结果" | 补充具体说明"前问的XX用于后问的YY" |
