# AI常见自证式论证模式库（数学建模版）

## 核心原理

**自证式论证**：模型选择的理由只包含模型本身的特性，而不涉及本题的特殊性。

```
❌ 自证式：因为这个模型精度高、效率高、鲁棒性强，所以选它
✓ 有依据：因为本题的碰撞对象是凸多边形(≤3个)，
          而SAT的O(n)复杂度最优，所以选它
```

## 🔴 高风险模式库

### Pattern 1: 模型名称复杂，但实现细节不清楚

**特征**：模型名字很"高大上"，但无法说明改进了什么、参数来自何处

```
❌ 高风险示例
"采用改进的遗传算法进行路径优化"
"利用融合算法进行多目标求解"
"基于优化的神经网络模型"

✓ 低风险示例
"采用标准遗传算法，交叉概率Pc=0.8，变异概率Pm=0.01，参考文献[X]"
"采用改进的遗传算法，改进点包括：(1)自适应交叉概率，(2)局部搜索融合，具体见公式(5)-(7)"
```

**检查方法**：
- 模型名字中有"改进""融合""混合""自适应"等词？
- 后续是否明确说了"改进了什么"？
- 有没有相关公式或参数说明？

### Pattern 2: 声称模型效果好，但没有对比基线

**特征**：用抽象的修饰词说效果好，但没有与替代方案的对比数据

```
❌ 高风险示例
"该算法精度高、效率高、稳定性好"
"相比传统方法，本模型优势明显"
"该方法具有较强的鲁棒性"

✓ 低风险示例
"采用SAT算法相比蛮力搜索(O(n²))，时间复杂度降低到O(n)，速度提升15倍(见表8)"
"参数±10%变化时，结果偏差<0.1%，具有较强的鲁棒性"
```

**检查方法**：
- 看这些词后面有没有跟具体的数字、百分比或对比？
- "精度高"后面有没有"精度为10^-12 m"这样的量化？
- "相比传统方法"是否给出了具体的对比对象和指标？

### Pattern 3: 超参数调优过度，但未说明必要性

**特征**：论文中大量调参，但没有说明为什么要调、调整范围和方法

```
❌ 高风险示例
"通过网格搜索调优了5个超参数，最终获得最优结果"
"经过多次参数调整，模型精度达到XX%"
"采用贝叶斯优化进行参数寻优"

✓ 低风险示例
"参数Pc=0.8, Pm=0.01遵循文献[X]的推荐值，已在相似问题中验证，无需额外调优"
"步长Δt=0.5s，由计算精度需求(要求<10^-4 s)和龙头速度(1m/s)推导，无需调整"
```

**检查方法**：
- 论文中出现"调优""优化参数""网格搜索"等词？
- 是否说明了为什么要调这些参数？
- 调整范围和方法有没有明确的依据？

### Pattern 4: 模型通用化声明，但缺乏边界限定

**特征**：夸大模型的应用范围，声称可"广泛应用"但不说明条件

```
❌ 高风险示例
"该模型可广泛应用于各种工程优化问题"
"本方法可用于路径规划、轨迹优化、资源分配等多个领域"
"该框架的通用性强，适用范围广"

✓ 低风险示例
"该模型在螺距范围[0.30-0.56]m内有效；若螺距扩大至[0-1]m，需要分段处理"
"SAT算法适用于凸多边形碰撞检测；若需要处理凹多边形，应考虑GJK或OBB方法"
```

**检查方法**：
- 论文最后的"应用推广"章节是否只是列举领域，没有实际验证？
- 模型的适用条件有没有明确限定（约束、数据范围等）？
- "广泛应用于"后面是否都是假设性的说法？

### Pattern 5: 问题与模型的个数不匹配，存在冗余

**特征**：5个问题却建立了7-8个不同的模型，很少复用，显得"大而全"

```
❌ 高风险示例
5个问题：
  Q1: 建立模型1（位置追踪）
  Q2: 建立模型2（碰撞检测）
  Q3: 建立模型3（参数搜索）
  Q4: 建立模型4（曲线设计）
  Q5: 建立模型5（速度计算）
  + 建立改进模型6和融合模型7
  → 共7个模型，几乎没有复用，显得"拼装"

✓ 低风险示例
5个问题：
  Q1-Q5: 都基于"约束优化"这个核心框架
         Q1: 螺线约束下的位置优化
         Q2: 碰撞约束下的停止判定
         Q3: 距离约束下的参数搜索
         Q4: 长度约束下的曲线设计
         Q5: 速度约束下的最大值求解
  → 共1个核心框架 + 5个变体，逻辑一致
```

**检查方法**：
- 数一下论文中有多少个不同的"模型"
- 是否存在重复的或功能相似但名字不同的模型？
- 核心思路是否贯穿全文，还是每问一个新模型？

## 🟡 中等风险模式库

### Pattern 6: 模板化建模流程，但缺乏本题特征

**特征**：按照通用模板建立模型（问题分析→建立模型→求解→验证），但模板感强

```
❌ 中等风险示例
问题分析：
  "问题要求在约束条件下求解最优值"
模型建立：
  "采用规划模型进行求解"
求解：
  "利用算法求得最优解"
验证：
  "对模型进行灵敏度分析验证"

✓ 低风险示例
问题分析：
  "问题1要求在螺距p=0.55m的约束下，计算224把手在螺线上的位置"
模型建立：
  "采用等距螺线的参数化表示(公式1)，利用弦长约束(公式2)推导位置方程(公式3)"
求解：
  "将224个把手的圆周分位按公式(3)代入MATLAB求解，得到位置列表（见表2）"
验证：
  "任意两个相邻把手的沿弦长距离均为0.275m，验证分角均匀（见图3）"
```

**检查方法**：
- 问题分析是否用了具体的数字、约束、变量？
- 模型建立是否说明了为什么选这个模型、如何映射到本题？
- 求解和验证是否用了本题的具体数据和结果？

### Pattern 7: 跨问联动不明确

**特征**：声称"基于前问的结果"，但没有明确说用了什么、用到哪里

```
❌ 中等风险示例
Q2结尾："求得停止时刻t*=412.47s"
Q3开头："基于前问的结果，进行最小螺距的计算"

✓ 低风险示例
Q2结尾："求得停止时刻t*=412.474s，此时龙头与磁盘无接触"
Q3开头："基于Q2的停止时刻t*=412.474s，此时龙头在O'处，距离调头中心R=4.5m，
        以此作为Q3搜索最小螺距p*的初值条件和距离约束"
```

**检查方法**：
- 论文中出现"基于前问""利用前问""根据前问"的地方有几处？
- 每处后面是否都明确说了"用了什么数据"和"用到哪个变量或约束"？

## 🟢 低风险特征（参考）

### ✓ Good Pattern 1: 问题→约束→模型的明确映射

```
"问题1要求在螺距p=0.55m的恒定约束下，计算224个把手的位置。
 我们采用阿基米德螺线的参数化表示(公式1)，其中p=(弦距)/旋转圈数)=0.55m，
 将每个把手的圆周分位(0°, 360°, ..., 81920°)代入公式(2)计算...,
 最终得到224个把手的XY坐标(表2)。"
```

特点：
- 问题明确（要求什么）
- 约束明确（条件是什么）
- 模型选择有理由（为什么选这个）
- 本题映射清楚（怎么用到本题）

### ✓ Good Pattern 2: 参数溯源完整

```
"步长Δt=0.5s选择依据：
 • 龙头速度v=1m/s，每步移动距离=0.5m
 • 螺线弦长精度要求：相邻两点弦长<0.5m
 • 数值求解精度要求：<10^-4 s
 综合以上条件，Δt=0.5s是合理的（见表X）"
```

特点：
- 参数来源明确（从何而来）
- 推导过程清晰（怎么得出的）
- 与其他约束的关系明确（为什么这个值合适）

### ✓ Good Pattern 3: 模型选择论证完整

```
"二分搜索vs替代方案：
 • 线性搜索：遍历[0.30-0.56]每0.01m，需50次迭代，太多
 • 三叉搜索：O(log₃n)相比O(log n)仅快10%，但代码复杂度翻倍，不值得
 • 随机搜索：无法保证最优解，竞赛不适用
 因此选择二分搜索O(log n)，平衡了效率和代码简洁性"
```

特点：
- 考虑了替代方案（不是唯一选择）
- 有定量的对比（具体的复杂度和差异）
- 说明了取舍（为什么不选其他）

## 💡 如何修改高风险模式

### 修改原则

1. **保留事实和数学含义** — 不要虚构数据或过程
2. **补充本题特征** — 说明"为什么这个模型适合本题"
3. **量化所有声称** — 用数字替代"高""强""好"
4. **追踪参数来源** — 每个参数都要说明"从哪来"
5. **明确跨问对接** — 说清"用了什么"和"用到哪里"

### 修改步骤

```
第1步：找出论文中所有高风险模式
第2步：逐一补充缺失的"本题特征"信息
第3步：用定量表述替代定性修饰
第4步：追踪参数来源，建立"参数溯源表"
第5步：明确问间数据流，画出"依赖图"
```
