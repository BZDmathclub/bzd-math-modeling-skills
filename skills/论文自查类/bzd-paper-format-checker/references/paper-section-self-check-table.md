# 数学建模论文各板块自查表

本表是 `bzd-paper-format-checker` 的内部逐项检查模板，不作为 Excel 或其他表格文件交付。状态填写：`满足 / 不满足 / 部分满足 / 无法核验 / 不适用`。

## 计分规则

- 基础分 15 分；每个独立观察点未满足扣 1—2 分。
- 一般完整性、统一性或清晰度问题扣 1 分；系统性错误、严重影响阅读或资格的问题扣 2 分。
- 得分允许为负，最低 -9999；资格风险单独标记，不能被分数抵消。
- 每项必须记录页码、标题、图表号、公式号或原文证据。
- 动态表须按实际问题、模型、段落、图表或公式复制，不得只抽查少量内容。
