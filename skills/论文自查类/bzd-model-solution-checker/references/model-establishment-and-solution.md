# 模型建立、求解与结果审查规则

## 完整闭环

每个问题应能够追踪到：任务目标、输入数据、数学类型、模型选择、变量参数、核心公式、求解算法、指定结果和结果解释。允许根据题型调整章节，不要求机械套用统一标题。

## 数据与预处理

- 多问共用数据时，公共处理集中说明；独立数据在对应问题内说明；部分共用时采用“公共处理＋专属处理”。
- 必须说明来源、字段、样本量、时间范围和统计口径。
- 缺失、异常、重复、标准化、编码、特征构造、降维和数据集划分均需说明必要性、方法、处理数量及对分布或后续模型的影响。
- 不能只写“进行了清洗”，也不能在没有数据证据时虚构缺失值、异常值或分布特征。

## 模型选择与针对性

- 先明确问题目标、输入、输出和数学类型。
- 选择理由应对应时间性、非线性、多目标、整数决策、随机性、空间网络等真实特征。
- 经典模型必须替换为本题的对象、变量、参数、目标、约束和输出。删除赛题背景后仍可直接用于任何论文的长段原理介绍，针对性不足。
- 多模型方案需说明比较标准和最终用途，不能只堆砌模型名称。
- “改进模型”必须指出原模型不足、具体改动和验证改进效果的方法。

## 数学表达

- 首次出现的变量、参数、集合、下标、单位和取值范围必须说明。
- 公式前说明建立目的，公式后解释每一项、参数来源、实际意义和与前后步骤的关系。
- 参数来源可为题目、附件计算、拟合、历史数据、文献、专家经验、合理假设、实验或优化求解，但必须可追踪。
- 约束应对应现实限制，例如资源、时间、容量、预算、整数、平衡、边界或逻辑约束。
- 优化模型应在求解前集中给出目标函数、全部约束和变量域，避免分散在多页后直接调用算法。

## 跨问题联动

真实联动必须体现在输入数据、指标、参数、目标函数、约束、初始值、情景或结果比较中。“基于问题一”但重新独立计算，不构成数据联动。前问结果进入后问时，应检查符号、单位和误差传播。

## 求解与复现

正文应说明：

- 算法名称、基本思想和适用理由；
- 输入、输出和关键步骤；
- 参数设置和来源；
- 初始条件与终止条件；
- 软件、必要版本和工具包；
- 随机种子或多次运行设计；
- 代码和完整结果所在附件。

“使用Python求解”不构成可复现说明。正文不应大段粘贴代码，可保留流程图、伪代码、关键参数和收敛说明。

智能优化算法还应核对编码、初始种群或初始解、适应度函数、选择/交叉/变异或对应更新规则、种群规模、迭代次数、停止条件、多次运行和收敛曲线。不同算法只检查与其机制相关的参数，不机械要求全部字段。

## 结果与图表

- 结果必须逐项回答赛题要求，包含必要数值、单位、方案、排序、文件或建议。
- 不能只写“效果较好”，应给出数值证据及现实解释。
- 说明结果含义、合理性、异常原因、实际价值、适用范围和局限。
- 图用于趋势、分布和关系；表用于精确数值和少量比较。避免图、表、正文三次重复同一数据。
- 每个图表应在出现前引出、在正文引用编号、出现后解释关键结论。
- 检查图表编号、题注位置、坐标轴名称与单位、图例、清晰度以及图表变量与正文的一致性。
