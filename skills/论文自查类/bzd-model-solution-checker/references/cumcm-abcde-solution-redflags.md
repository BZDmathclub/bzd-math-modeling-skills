# CUMCM A—E 题模型建立与求解红线

## 使用规则

先根据当前题目定义审查基准，再调用对应题型。以下红线只有在当前赛题存在相同数学机制时才适用。不同但正确、完整、可复现的方法不得扣分。历史结果和2026预测不得作为当前论文正确性的证据。

## A：工程机理与数值仿真

- 方程必须有几何、运动、守恒、能量或其他机理来源；坐标、单位、初边值统一。
- 有面积/体积/宽度的对象不能无依据退化为点或线；碰撞、覆盖、遮挡要检查完整对象。
- 积分、求根、递推、射线和离散计算必须说明步长、容差、初值、根选择和收敛。
- 优化须说明变量范围、参数、约束处理和停止条件；候选最优解须高精度复算并逐条验约束。
- 年度索引：FAST球面与拉索；波浪能耦合与稳态平均；定日镜锥角和完整效率；板凳龙矩形碰撞；烟幕圆柱遮蔽、区间并集和采样收敛。

## B：有限观测与推断决策

- 不能使用题目禁止的信息；先验证目标量可识别、解唯一/稳定且对噪声不过敏。
- 比例、角度、频谱、空间和二项数据应匹配相应变换、似然或几何关系。
- 异常删除、滤波、寻峰和阈值必须有规则、参数与前后影响。
- R²或结果接近不能单独证明可靠；需残差、重构、区间、跨条件或独立方法验证。
- 年度索引：C4烯烃比例与实验设计；纯方位禁用坐标；多波束重叠率与坐标复核；生产抽检与拆解递推；碳化硅色散、多光束和反射率重构。

## C：特殊数据结构与决策

- 区分结构零、缺失和真实零；处理成分、重复测量、时间、层级和跨期依赖。
- 时间数据不能随机验证，同一对象重复样本不能跨训练/测试；防止派生变量泄漏。
- 预测、评价和分类结果必须进入后续决策；优化须包含题面全部逻辑与跨期硬约束。
- 从最终附件重新读取方案、逐条验约束并独立重算利润、目标或准确率。
- 年度索引：供应链订货—供货—库存；玻璃CLR与无配对标签；蔬菜价格—需求—补货；种植MILP硬约束；NIPT重复测量、Cox/分位数、质控和三区判定。

## D：复杂规则与动态系统

- 必须有一般模型、状态更新和算法逻辑，不能只交一张具体结果表。
- 有业务优先级的多目标不能随意线性加权；应使用分层、字典序或约束转化。
- 异常发生后状态、流量、速度、资源或边权必须动态更新，必要时重规划。
- 概率事件区域、条件分布和联合积分须正确；蒙特卡洛须说明抽样、样本量、误差和随机性。
- 年度索引：连铸二次切割与在线调整；通信容量和联合成功；湖羊阶段与栏位估算；深弹三维事件；矿井分叉汇合与时间依赖最短路。

## E：数据语义与可信部署

- 定义字段、单位、样本、标签和预测时可获得信息；禁止未来信息和同主体近重复泄漏。
- 验证方式须匹配任务：分层、按主体分组、时间滚动或区域/场景留出。
- 复杂度须匹配样本规模、维度、类别平衡和标签完整度；必须与透明基线公平比较。
- 结果应报告分组指标、不确定性和典型误差，并转成可执行行动及边界。
- 年度索引：光谱高维连续与半监督；物料预测—库存闭环；水文概念与时空监测；交通全局协调；体测关键阶段与小样本分组验证（非官方评阅归纳）。

## 共通审计

1. 任务—模型—算法—结果—验证逐项对应。
2. 参数来源、单位、范围、初值、终止条件和随机性可追踪。
3. 前问输出真实进入后问，误差在需要时向后传播。
4. 结果直接回答全部任务，正文、图表、代码和附件一致。
5. 采用量纲/守恒/残差/留出/收敛/可行性/敏感性中与模型相匹配的验证。
