# 模型检验、灵敏度、稳健性与误差审查规则

## 模型检验

模型检验回答“模型是否满足使用条件、结果是否可信”。

### 使用前检验

用于检查模型成立条件，例如AHP一致性、灰色预测准指数规律、时间序列平稳性、回归显著性、正态性、独立性、多重共线性、异方差、自相关和聚类数合理性。只在对应模型确实需要时检查。

### 使用后检验

用于检查结果可靠性，例如训练/测试比较、预测与真实值比较、交叉验证、留一法、残差分析、现实或文献对照、基准模型比较、多次随机运行和仿真对照。

### 模型—指标匹配

- 预测：MAE、MSE、RMSE、MAPE、决定系数、残差；
- 分类：准确率、精确率、召回率、F1、ROC/AUC、混淆矩阵；
- 聚类：轮廓系数、CH指数、DB指数、聚类稳定性；
- 优化：约束满足、收敛曲线、重复运行、基准算法、上下界或最优性差距；
- 评价：排名一致性、权重稳定性、赋权方法对比、现实或专家排序对照。

检验必须给出统计量或误差、判定标准、数据划分或对照对象和结论。训练集拟合好不等于泛化可靠。检验不通过时，应修改模型、假设或适用范围。

## 灵敏度分析

灵敏度分析回答“输出对关键参数变化有多敏感”。检查：

1. 参数是否直接影响目标、来源不确定、可调或可能改变结论；
2. 基准值和变化范围是否来自历史范围、置信区间、现实边界、政策工程约束或文献；
3. 单因素分析是否保持其他条件不变；
4. 多因素分析是否考虑交互，并采用正交试验、响应面、网格、蒙特卡洛、方差分解、Sobol或情景组合等合适方法；
5. 是否展示参数—输出关系；
6. 是否明确最敏感参数、稳定区间和变化方向；
7. 参数扰动是否改变排名、最优方案或结论方向。

相对灵敏度可表示为：

`S = (ΔY / Y) / (ΔX / X)`

但不强制所有论文使用该系数。变化范围不能无依据统一设为±10%，也不能设置脱离现实的极端值。

## 稳健性分析

稳健性回答“数据、样本、初始条件或模型设定变化后，主要结论是否仍成立”。可改变数据扰动、样本规模、异常处理、权重方法、初始值、模型假设、算法或训练测试划分。关注趋势、排名、方案和结论是否稳定，而非数值完全不变。

## 误差分析

误差分析回答“误差多大、从哪里来、是否影响结论”。检查是否考虑测量、缺失填补、异常处理、样本代表性、模型简化、参数估计、数值计算、随机算法、软件精度和跨问题传播误差，并尽量给出平均误差、最大误差、区间或置信区间。

## 三者边界

- 灵敏度：改变参数，观察输出响应；
- 稳健性：改变数据、样本、模型条件或算法，观察主要结论是否保持；
- 误差分析：量化误差并解释来源和影响。

一张参数变化曲线不等于完整灵敏度分析；一段“结果变化不大”不等于稳健性证据；只列误差来源而不量化也不构成充分误差分析。

## 常见严重问题

- 检验方法与模型类型不匹配；
- 只有“通过检验”而无量化结果和阈值；
- 使用训练数据同时拟合和证明泛化能力；
- 参数范围无依据或只分析无关参数；
- 灵敏度实验显示方案或排名改变，却仍声称模型稳定；
- 检验结果否定关键假设，但正文不修改模型或适用范围；
- 前问误差进入后问，却完全忽略误差传播。
