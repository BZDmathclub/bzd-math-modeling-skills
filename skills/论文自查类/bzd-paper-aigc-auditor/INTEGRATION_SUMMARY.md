# bzd-paper-aigc-auditor v2.1 增强整合总结

## 📋 项目背景

用户基于已完成的第二层（模型合理性深度审查）和现有的第一层框架，要求将nature-AIGC-detector的方法论融入第一层，使语言特征检测更加全面。

---

## 🎯 整合目标

**原始状态**（v2.0）
- 第一层：6维语言特征（高频词、排比、拔高词、被动句、段落规律、文本复杂度）
- 第一层输出：单纯的语言层面评分
- 缺陷：无事实验证层（无法检测虚构引文、数值矛盾、术语混乱）

**目标状态**（v2.1）
- 第一层：9维框架（6维语言 + 3维事实）
- 第一层输出：语言层面（60%）+ 事实层面（40%）的综合评分
- 增强：融合nature-detector的引文验证、数值追踪、术语检测

## 📊 权重重新分配

### v2.0的权重
```
第一层总分 = 
  (语言模板化 × 0.6) +
  (其他四维: 结构15% × 0.4 + 建模30% × 0.4 + 求解20% × 0.4 + 来源10% × 0.4)
```

### v2.1的权重（新增事实层）
```
第一层总分 = 
  [语言层面] (权重60%)
    维1: 高频连接词         12%
    维2: 排比/同构句式      7.2%
    维3: 拔高词(5级)        7.2%
    维4: 被动句占比         5.4%
    维5: 段落规律性         3.6%
    维6: 文本复杂度         0.6%
  +
  [事实层面] (权重40%) 【新增】
    维7: 引文验证(L1-L3)    15%
    维8: 数值一致性         15%
    维9: 术语一致性         10%
```

**权重变化说明**：
- 维1-6：原有的语言特征权重不变（仍60%），但内部比例有调整
- 维7-9：全新增加的事实验证层（40%权重）

## 📌 具体改进示例

### 例1：拔高词检测的升级

**v2.0**：
```
❌ "该方法具有显著优势"
判定：拔高词无据 → 扣分
```

**v2.1**：
```
❌ "该方法具有显著优势" → L1级（绝对化+无数据）→ 0分
⚠️  "相比传统方法优势明显" → L2级（相对化+泛泛对比）→ 30分
△ "模型精度为99%" → L3级（定量+无基准）→ 70分
✓ "精度99.2% vs基准89.5%，提升10.7百分点" → L5级 → 100分
```

### 例2：术语一致性检测（新增）

**无法在v2.0中检查**

**v2.1**：
```
构建追踪表：
┌──────────┬───┬───┬───┬─────────┐
│核心术语  │P1 │P5 │P10│一致性   │
├──────────┼───┼───┼───┼─────────┤
│算法      │GA │GA │GA │✓一致   │
│运次数    │运次│班次│运次│△混用   │
│多架次    │多设│多架│联合│🔴混乱 │
└──────────┴───┴───┴───┴─────────┘

判定：术语混用严重 → 30分
改进方向：统一术语表述
```

### 例3：引文验证（新增）

**无法在v2.0中检查**

**v2.1**：
```
L1格式检查（30秒）：
✓ DOI: 10.1234/journal.2020.001234（正确格式）

L2存在性验证（2分钟）：
✓ Google Scholar 搜索找到该文献
✓ 作者、题名、年份都匹配

L3主张验证（5分钟）：
论文声称："根据XXX文献的遗传算法方法"
查验原文：该文献确实介绍了GA，但是用于图像识别
问题：两个领域应用差异大，需要补充"为什么GA在本题也适用"的论证

最终判定：引文存在但应用论证不足 → 70分
```

## 🚀 实施流程的改进

### v2.0: 单一流程
```
阅读五维标准 → 逐一评分 → 汇总得分
时间：20分钟（不区分快速/详细）
```

### v2.1: 两阶段流程

**阶段1：快速筛选（5-8分钟）**
```
□ 高频连接词密度 < 15%?
□ TTR > 0.5?
□ 被动句占比 < 25%?
□ 拔高词L1-L2 < 3个?

→ 所有通过 → 速判为低-中风险，重点进入第二层
→ 有问题 → 进入阶段2深度检查
```

**阶段2：深度检查（10-15分钟）**
```
连贯性分析 → 事实验证 → 逻辑与完整性 → 综合判分
因果链  /  引文验证  /  内部矛盾  /  总得分
代词指代 /  数值追踪  /  假说对齐  /
时间序列 /  术语追踪  /  凝聚力   /
```

**优势**：
- 低风险论文可快速处理（节省10分钟）
- 中风险论文深度检查（节省确认时间）
- 高风险论文可精准定位问题根源

## ✨ 核心增强点总结

### 新增检测能力
1. **引文真实性验证**（L1-L3三层）→ 发现虚构或幻觉
2. **数值参数追踪**→ 发现计算错误或虚构数据
3. **术语一致性检测**→ 发现概念混乱
4. **科学复杂度度量**（TTR、n-gram、熵值）→ 定量识别模板特征

### 改进的检测精度
1. **拔高词分级**→ 从二元到五级细粒度评估
2. **段落规律性定量化**→ 从定性观察到百分比统计
3. **两阶段流程**→ 快速筛选 + 深度验证的分层模式

### 特化于数学建模
1. nature-detector方法 + 数学建模竞赛常识的结合
2. 参数追踪表针对"赛题给出/前问推导/物理约束"三级源头
3. 术语追踪特别关注"算法名称、数据集、约束条件"等关键术语
