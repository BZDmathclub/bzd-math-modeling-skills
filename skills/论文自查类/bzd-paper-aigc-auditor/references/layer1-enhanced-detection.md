# 第一层增强检测框架 v2.1
## 融合nature-AIGC检测方法的多维语言+事实分析

---

## 概述

第一层检测重点：**快速筛选AI特征**（权重60%）

原框架：高频连接词 + 排比句 + 同构句式 + 拔高词 + 被动句  
**增强框架**：融合nature-AIGC-detector的5大维度检测

---

## 一、核心框架：9维融合检测模型

### 维度布局

```
语言层面（60%权重）：
├─ 维度1: 高频连接词（20%）→ Humanizer-zh
├─ 维度2: 排比/同构句式（12%）→ 同构模式识别
├─ 维度3: 拔高词与修饰词（12%）→ 无数据修饰词
├─ 维度4: 被动句占比（9%）→ 语态分析
├─ 维度5: 段落规律性（6%）→ 段落结构
├─ 维度6: 文本复杂度（1%）→ 熵值/n-gram分析

事实层面（40%权重）：
├─ 维度7: 引文验证（15%）→ nature-detector的L1-L3验证
├─ 维度8: 数值一致性（15%）→ 参数追踪
└─ 维度9: 术语一致性（10%）→ 概念跟踪
```

## 二、语言层面检测（维度1-6）

### 2.1 高频连接词检测

**基础词库（已有）**：
综上所述(5★)、进一步(4★)、此外(3★)、与此同时(3★)、值得注意的是(3★)、可以看出(4★)、一般来说(3★)、由此可见(3★)、不仅...而且(3★)、当然(2★)

**增强词库（数模特化）**：
```
新增高危词汇：
- "具有...特性" → 通常后面接结论而无具体数据
- "相对而言" → 常用于模糊对比而无数字
- "显然" → 跳过推导的表现
- "毋庸置疑" → 强行下结论，AI常用
- "可以看出" → 经常用于伪推导或泛泛而谈
```

**检查方法**：
```
密度计算：
  高频词总出现次数 / 全文总句数

判定标准：
  <15%      🟢 低风险
  15-20%    🟡 中低风险（轻微AI特征）
  20-25%    🟠 中风险（明显AI特征）
  >25%      🔴 高风险（严重套话）

聚集检查：
  同一词在3页内出现>2次 = 套话风险
```

---

### 2.2 排比与同构句式检测

**风险分级**：

```
🔴 L1高风险排比：
"该方法具有以下优点：(1)准确度高、(2)效率快、(3)鲁棒性强"
→ 排比后全是抽象形容词，无数据

⚠️  L2中等风险排比：
"约束条件：(1)螺距p≥0.30m、(2)转向半径R<4.5m、(3)速度v≤2m/s"
→ 有数字，但缺乏**来源解释**

✓ L3安全排比：
"约束条件：(1)螺距p≥0.30m(赛题)、(2)R<4.5m(推导)、(3)v≤2m/s(安全系数)"
→ 每项都有来源说明
```

**检查清单**：
- 排比项>5时，是否全部都有量化支撑？
- 同构句是否每一项都涉及不同的**真实对象**？
- 是否存在"枚举感"而无逻辑递进？

---

### 2.3 拔高词与修饰词检测（5级分类）

```
L1 【最高风险】绝对化 + 零数据
❌ "模型精度最高"、"算法最优"
✓ 改为："与基准相比，精度提升64.7% (0.34→0.56)"

L2 【高风险】相对化 + 泛泛对比
❌ "相比传统方法，性能有很大提升"
✓ 改为："相比蛮力搜索O(n²)，二分搜索O(log n)快100倍"

L3 【中风险】定量 + 无基准
❌ "精度为99%"
✓ 改为："在500样本测试集上，精度99.2% (vs基准89.5%)"

L4 【中低风险】定量 + 有数字无对比
❌ "计算时间0.5秒"
✓ 改为："0.5秒 vs 竞品2.3秒，快3.6倍"

L5 【低风险】完整定量 + 充分对比
✓ "与KNN相比，F1提升12.5-18.7%，在D1上最高提升20.1%"
```

**检查方法**：
- 统计L1-L2级拔高词：>3个为警戒
- 拔高词密度：>15% 为警戒

---

### 2.4 被动句占比分析

```
正常范围：10-20%
AI特征：>25-30%（显得学术但不自然）

高风险示例：
"该模型被应用于... | 结果被验证... | 参数被优化..."
→ 整段都是被动语态，显得生硬

低风险示例：
"我们建立了该模型... 结果验证了... 通过分析，我们发现..."
→ 主动和被动混合，自然流畅

检查方法：
1. 抽取论文3-5段，统计被动句占比
2. 是否出现连续>3句都是被动语态？
3. 被动句中是否都有**明确的执行者**？
```

---

### 2.5 段落结构规律性检测

```
AI特征：段落高度规律化
- 每段长度恰好3-4句话
- 每段都以相同词开头（"为了""通过""采用"）
- 开头方式重复>50%

正常特征：段落自然多样化
- 段长在2-6句间自然波动
- 开头方式多样（"根据""利用前问的""因此""相比之下"）
- 句式长短交错，形成节奏感

检查方法：
1. 抽取20段，统计段长分布
2. 开头词的重复率：>30% = 规律过高
3. 逻辑递进：是否有"明确的承接"（如"由上可知""基于此"）
```

---

### 2.6 文本复杂度分析

#### A. 熵值分析（Entropy）
```
正常特征：文本熵值在3.5-4.5 bits/char间波动
AI特征：熵值过低或过度均匀（可预测度过高）

定性检查：
- 随机截取200字，观察词频
- 是否频繁出现相同词组？
- "高频词占比"是否>30%？
```

#### B. n-gram频率分析
```
高风险特征（3-gram不自然）：
"本文采用...本文选择...本文利用...本文验证..."
→ "本文+动词"组合频率>3次为警戒

"通过...方法...通过...算法...通过...分析..."
→ "通过"频率>4次 + 后接词汇单一 = 严重套话

检查清单：
- "本文+动词"组合：>3次? → 警戒
- "通过+名词"组合：>4次? → 警戒
- 其他高频词(采用、利用、基于)后接词汇单调度？
```

#### C. 词汇多样性（TTR = Type-Token Ratio）
```
计算：不同词数 / 总词数

标准：
  >0.6      正常（词汇丰富）
  0.5-0.6   正常
  0.4-0.5   轻微警戒（词汇重复过多）
  <0.4      高风险（AI特征：重复词过多）
```

## 三、事实层面检测（维度7-9）

融合nature-AIGC-detector的5大维度中的事实验证部分

### 3.1 引文验证（15%权重）

#### L1【快速检查】30秒
```
格式检查：
✓ DOI格式正确？(10.XXXXX/...)
✓ 作者名规范？(Lastname, F.I.)
✓ 期刊名格式？(通常Capitalized或全大写)
✓ 发表年份合理？(通常不超过20年，除非经典)

风险信号：
❌ DOI格式错误 → 虚构可能性高
❌ 作者名非标准格式 → 可能伪造
❌ 论文发表年>30年(非综述)→ 可疑
```

#### L2【存在性验证】2-3分钟
```
验证途径：
1. Google Scholar (scholar.google.com)
2. 知网 (cnki.net) 或 PubMed (pubmed.ncbi.nlm.nih.gov)
3. 期刊官网

检查内容：
✓ 文献是否存在？
✓ 作者、题名、年份是否匹配？
✓ DOI是否正确对应？

高风险信号：
❌ 无法找到 → 虚构可能性极高
❌ 题名不匹配 → 伪造或致命错误
```

#### L3【主张-支撑匹配】5分钟（仅抽查3-5篇关键文献）
```
检查点：
1. 论文中"根据XXX文献，模型采用..."
   → 查验该文献中是否真的提出了这个模型
   
2. "数据来自XXX数据集"
   → 验证该数据集是否存在、规模是否一致
   
3. "按照XXX的方法论"
   → 抽查该文献，方法描述是否一致

高风险信号：
❌ 文献主张与论文引用不符
❌ 数据集规模虚报（例：声称用ImageNet但实际用CIFAR）
❌ "改进XXX方法"但无具体改进说明
```

**数学建模特化版**：
```
检查关键词：
- "根据题意" → 是否有赛题原文支撑？
- "参考文献[X]中的算法" → 该算法在文献中是否有相同的使用场景？
- "数据集包含XXX个样本" → 是否与赛题数据规模一致？
```

### 3.2 数值一致性检测（15%权重）

**参数追踪表**：

```
构建追踪表格：
┌────────┬──────────────┬──────┬──────┬──────┐
│ 参数   │ 首次出现位置 │ P值  │ 使用位置 │ 一致 │
├────────┼──────────────┼──────┼──────┼──────┤
│ p=0.55 │ P1(赛题给出) │0.55 │P3,T1,... │ ✓   │
│ v=1m/s │ P2(推导得)   │1.0  │P5,公式3  │ ✓   │
│ Δt=0.5s│ P6           │0.5  │表2,代码  │ ✓   │
└────────┴──────────────┴──────┴──────┴──────┘

检查方法：
1. 列出论文中的所有关键参数
2. 追踪每个参数在全文的使用位置
3. 是否存在"P1=0.55, P10=0.54"的矛盾？

判分标准：
✓ 完全一致           → 100分
△ 轻微波动(±1%)     → 70分（可能舍入）
✗ 明显矛盾(>5%)    → 0分（可能造假或计算错误）
```

**数值来源三级体系**：
```
L1【赛题给出】：直接来自问题陈述
  例："螺距p=0.55m（题目给出）"
  风险：低

L2【前问推导】：从前一问的结果得出
  例："Q2推导出停止时刻t*=412.474s，Q3利用此作为初值"
  风险：低（只要前问计算正确）

L3【物理/数学约束】：从基本原理推导
  例："Δt=0.5s由龙头速度v=1m/s和精度要求<10^-4s推导"
  风险：中（需要逻辑清晰）

🔴 无来源：凭空出现
  例："设步长Δt=0.5s" (无解释)
  风险：极高
```

### 3.3 术语一致性检测（10%权重）

**术语追踪表**：

```
构建追踪表：
┌──────────┬─────────────┬─────────────┬──────────┐
│ 核心术语 │ 在P_开头    │ 中文变体    │ 一致性   │
├──────────┼─────────────┼─────────────┼──────────┤
│ 直升机   │ P1          │ 直升机/直升│ 🟢 一致  │
│ 运次数   │ P2表1       │ 运次/班次   │ 🟡 混用  │
│ 多架次   │ P1摘要      │ 多架次/联合│ 🟢 一致  │
│ 驻点     │ P3          │ 驻点/停靠点│ 🔴 混用  │
└──────────┴─────────────┴─────────────┴──────────┘

检查方法：
1. 提取5-7个核心概念
2. 追踪其在全文的表述方式
3. 是否存在"一个东西用多个名字"的现象？

判分标准：
✓ 术语完全一致         → 100分
△ 偶有变体但无歧义     → 80分
✗ 同一术语3种以上名字 → 30分
```

**特别检查：算法和模型的术语**：
```
高风险示例（AI特征）：
P1: "采用遗传算法GA"
P5: "利用进化策略ES"  
P10: "该种群智能算法..."
→ 到底用的是GA、ES还是其他？显得概念混乱

低风险示例（清晰）：
全文统一术语：
"约束优化框架"
├─ Q1: 位置约束优化
├─ Q2: 燃油约束优化  
├─ Q3: 时间约束优化
→ 虽然内容不同，但框架名称统一
```

## 四、综合判分规则（9维模型）

### 4.1 维度权重总表

```
总体框架 = 语言层面(60%) + 事实层面(40%)

语言层面权重分配：
1. 高频连接词      20% × 0.60 = 12%
2. 排比/同构句     12% × 0.60 = 7.2%
3. 拔高词         12% × 0.60 = 7.2%
4. 被动句占比      9% × 0.60 = 5.4%
5. 段落规律性      6% × 0.60 = 3.6%
6. 文本复杂度      1% × 0.60 = 0.6%
                        小计: 60%

事实层面权重分配：
7. 引文验证        15% × 1.0 = 15%
8. 数值一致性      15% × 1.0 = 15%
9. 术语一致性      10% × 1.0 = 10%
                        小计: 40%
                        
总计：100%
```

### 4.2 评分方法

```
第一层最终得分 = 
  (维1得分×0.12 + 维2得分×0.072 + ... 维6得分×0.006) +
  (维7得分×0.15 + 维8得分×0.15 + 维9得分×0.10)

风险等级划分：
0-20   🟢 低风险
21-35  🟡 中低风险
36-54  🟠 中风险
55-74  🔴 中高风险
75-100 ⛔ 极高风险
```

## 五、实施流程（两阶段检查）

### 阶段1：快速筛选（5-8分钟）
```
Step 1: 统计特征快速扫描
  ✓ 高频连接词密度（目标：<15%）
  ✓ 被动句占比（目标：15-20%）
  ✓ 拔高词频次（目标：<5个L1-L2级）
  ✓ TTR值（目标：>0.5）
  
  决策：如果所有指标都很好 → 得分可能≥60 → 后续重点转向第二层
        如果有2+个指标不良 → 进入阶段2深度检查
```

### 阶段2：深度检查（10-15分钟）
```
Step 2: 连贯性分析
  ✓ 因果链完整性（每个结论都有推导吗？）
  ✓ 句级指代清晰度（代词使用是否过频？）
  ✓ 时间序列合理性（问间顺序、步骤顺序正确吗？）

Step 3: 事实与一致性
  ✓ 引文验证（L1-L3，抽查3-5篇关键文献）
  ✓ 数值追踪（参数是否始终一致？）
  ✓ 术语追踪（同一概念用词是否稳定？）

Step 4: 逻辑与完整性
  ✓ 内部矛盾检测（是否存在"A和¬A"的表述？）
  ✓ 假说-方法-结果对齐（逻辑链是否严密？）
  ✓ 段落凝聚力（是否像独立模块还是有机整体？）
```

## 六、高风险信号与优先级

```
🔴 立即标记（可能高风险）：
  • 连续>5页被动句占比>40%
  • TTR<0.3（词汇极度重复）
  • 3-gram重复率>15%
  • 发现明显的内部矛盾（"Q1用参数a=0.5, Q3用a=0.7"）
  • 引文验证不通过（虚构DOI或伪造作者）

🟡 需要重点审查：
  • 参数无来源说明
  • "基于前问"但没说具体用了什么
  • 模型选择无对比论证
  • 参考文献<5篇或>20篇

✓ 低风险指标：
  • 连接词密度<15%
  • TTR>0.55
  • 参数溯源完整
  • 引文验证通过
  • 术语使用一致
```

## 八、与第二层的协同策略

```
第一层得分 < 40  →  低优先级进入第二层
   理由：语言特征明显AI特征，应先改语言层面

第一层得分 40-60 →  同步进行第二层审查
   理由：语言层面可改善，同时需要逻辑审查

第一层得分 > 60  →  重点转向第二层深度检验
   理由：语言层面基本过关，关键是逻辑完整性

最终判决 = (第一层 + 第二层) / 2 → 综合风险等级
```
