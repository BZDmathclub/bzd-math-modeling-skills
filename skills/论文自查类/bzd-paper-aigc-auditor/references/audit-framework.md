# 数学建模论文AI痕迹审计框架

## 1. 五维100分风险框架

| 维度 | 权重 | 核心问题 |
|---|---:|---|
| 语言模板化 | 25 | 是否大量出现AI高频套话、机械连接、同构句式、虚假拔高和空泛结论 |
| 结构与论证模板化 | 15 | 是否章节齐全但功能重复，段落像清单，主张与证据不能对应 |
| 建模专属性 | 30 | 模型是否真正映射到赛题对象、数据、约束、变量、单位和输出 |
| 求解与验证闭环 | 20 | 算法、参数、结果、检验是否可追踪、可复现且前后一致 |
| 来源与一致性 | 10 | 引用、数据来源、代码、图表、术语和数值是否存在幻觉或冲突 |

每维先按0—100给风险，再乘权重。总分用于生成区间中心，不应直接称为“AI生成概率”。

### 风险等级

| 加权风险分 | 等级 | 含义 |
|---:|---|---|
| 0—19 | 低 | 主要是正常科技论文表达，未见系统性AI模板问题 |
| 20—34 | 中低 | 有局部套话或模板段落，但核心建模较具体 |
| 35—54 | 中 | 多个章节存在AI风格，仍能观察到实质建模工作 |
| 55—74 | 中高 | 语言和建模均明显模板化，人工核验链不足 |
| 75—100 | 高 | 大量空泛、拼装、断链或不可复现内容，需整体重构 |

结果区间以加权分为中心，根据材料完整性扩展：

- 只有论文：建议±8—12分，置信度最高为中；
- 论文+赛题：建议±6—10分，通常中等置信度；
- 论文+赛题+代码/数据/结果：建议±5—8分；
- 再有版本历史或真实使用记录：可评为高置信度，但仍不是作者身份鉴定。

## 2. 语言痕迹

只有形成重复模式并削弱信息密度时才计风险。

### 高风险模式

- 夸大意义：“具有至关重要的意义”“奠定坚实基础”“彰显巨大价值”；
- 空泛评价：“结果合理”“模型准确性较高”“具有较强鲁棒性”，但没有指标；
- 机械框架：“首先—其次—再次—最后”在多段重复；
- 三项排比和同构句连续出现；
- 过多“此外、与此同时、值得注意的是、综上所述”；
- 否定式排比：“不仅……而且……”“不是……而是……”高频出现；
- 泛化范围失真：“可广泛应用于交通、医疗、金融等多个领域”；
- 模糊来源：“研究表明”“专家认为”“相关资料显示”而无引用；
- 交流残留：“当然可以”“以下是为您生成的”“希望对您有所帮助”；
- Markdown或提示词残留、异常粗体、表情符号、占位符。

### 数模常用句，不能单独作为证据

- “针对问题一，建立……模型”；
- “由题意可知”“根据上述假设”；
- “结果如图/表所示”；
- “采用Python/MATLAB进行求解”；
- “对模型进行灵敏度分析”；
- “综上所述，模型为”；
- 模型、算法、检验和优化器的标准名称。

这些句子只有在没有具体对象、变量、参数、结果或证据时，才构成模板化风险。

## 3. 逐板块观察点

| 板块 | 重点AI风险 |
|---|---|
| 摘要 | 每问句式完全相同；只列模型名；数字与正文不一致；空泛创新和稳定性声明 |
| 问题重述 | 大段复述题干；擅自添加任务；出现“深入探讨”等泛化表达 |
| 问题分析 | 通用流程可替换到任意题；缺少数据、约束和跨问关系；提前编造结果 |
| 模型假设 | “数据真实可靠、模型正确”等自证假设；假设未在后文使用；与题意冲突 |
| 符号说明 | 符号表与正文不一致；出现模板遗留符号；单位缺失 |
| 模型建立 | 模型名称堆叠；公式与本题对象脱节；约束遗漏；所谓改进无数学定义 |
| 模型求解 | 只写“导入软件求解”；缺参数、初值、终止条件和复现路径 |
| 结果 | 只给图表不解释；数值没有单位或对象；答案没有逐项回应题目 |
| 检验与灵敏度 | 只说“效果良好”；指标与模型不匹配；检验图、数值或阈值缺失 |
| 模型评价 | 优点全是套话；缺点写“时间有限”；推广罗列无关领域 |
| 参考文献 | 不存在或拼接文献；正文与文末不对应；网址、DOI、年份冲突 |
| 附录 | 代码与正文变量不同；代码不能产生正文结果；保留对话、用户名或本机路径 |

## 4. 模型类型判定

| 类型 | 判断标准 | 常见结论 |
|---|---|---|
| 标准竞赛模型 | 有公认名称、定义和适用条件，且完成本题变量映射 | 正常，不因常见而判AI |
| 合理自定义模型 | 名称可自拟，但目标、约束、变量、参数和验证明确 | 正常或低风险 |
| 模板套用模型 | 只介绍百科原理，删除题目背景后可用于任何论文 | 中高风险 |
| 拼装模型 | 多个模型名串联，缺少接口、输入输出和必要性 | 高风险 |
| 伪改进模型 | 使用“改进、融合、自适应”等名称但无公式或算法变化 | 高风险 |
| 错配模型 | 数据结构、任务目标或假设不满足模型适用条件 | 高风险，但需避免把专业争议说成AI证据 |

常见数学建模模型包括但不限于回归、时间序列、聚类、分类、综合评价、规划优化、图论、微分方程、动力学、排队、库存、仿真和数值计算。机器学习或深度学习模型也可能完全合理；判断重点是适配与落地，而不是是否“高级”。

## 5. 修改原则

按以下优先级修改：

1. 补齐题目任务和关键约束；
2. 修复变量、单位、公式、参数和结果冲突；
3. 补充算法复现信息与量化检验；
4. 删除无证据的意义拔高和结论；
5. 合并重复段落，改变段落功能而非机械换词；
6. 使用本题对象、数据字段和结果数字替代通用表述；
7. 最后调整句式节奏和连接词。

不得通过以下方式“降AI感”：

- 故意加入错别字、病句或不规范术语；
- 随机替换专业名词；
- 虚构个人经历、情绪、实验细节或人工过程；
- 删除引用、限制条件和不确定性；
- 为躲避检测牺牲可读性和科技论文规范。
