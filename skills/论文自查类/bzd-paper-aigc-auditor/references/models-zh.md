# 数学建模常用模型库 vs AI高频模型对照表

## 📚 数学建模竞赛常用模型库

### 基础类（数据处理与拟合）

**✓ 回归分析**
- 线性回归 (Linear Regression)
- 非线性回归 (Logistic, Power Law, Exponential)
- 多元回归 (Multiple Linear Regression)
- 分段回归 (Piecewise Regression)
- 风险等级: 🟢低（CUMCM、美赛常见）

**✓ 时间序列**
- ARIMA 模型
- 指数平滑 (Exponential Smoothing)
- 移动平均 (Moving Average)
- 傅里叶级数 (Fourier Series)
- 风险等级: 🟢低（标配时间序列工具）

**✓ 聚类分析**
- K-means 聚类
- 层次聚类 (Hierarchical Clustering)
- 谱聚类 (Spectral Clustering)
- 密度聚类 (DBSCAN)
- 风险等级: 🟢低（分类问题标配）

**✓ 分类算法**
- 朴素贝叶斯 (Naive Bayes)
- 决策树 (Decision Tree)
- KNN 算法
- Logistic 回归
- 风险等级: 🟢低（但勿过度复杂化）

---

### 几何与碰撞类

**✓ SAT（分离轴定理）**
- 用途：凸多边形碰撞检测
- 复杂度：O(n)
- 适用场景：刚体碰撞、路径规划障碍检测
- 风险等级: 🟢低（几何问题标配）

**✓ 二分搜索**
- 用途：参数空间搜索、阈值查找
- 复杂度：O(log n)
- 适用场景：连续参数的最优值搜索
- 风险等级: 🟢低（优化问题标配）

**✓ 扫描线算法 (Sweep Line)**
- 用途：轨迹追踪、面积计算、事件驱动模拟
- 复杂度：O(n log n)
- 风险等级: 🟢低（路径问题常见）

**✓ 蒙特卡洛方法**
- 用途：数值积分、概率估计、随机模拟
- 复杂度：O(n)
- 风险等级: 🟢低（数值计算标配）

---

### 系统动力学

**✓ 微分方程**
- 常微分方程 (ODE)
- 偏微分方程 (PDE)
- 风险等级: 🟢低（动态过程建模）

**✓ 差分方程**
- 递推关系式
- 离散递推
- 风险等级: 🟢低（序列问题标配）

**✓ 传播模型**
- SIR/SEIR 模型
- 风险传播
- 风险等级: 🟢低（疫情/传播问题）

---

### 优化算法

**✓ 线性规划 (Linear Programming)**
- 单纯形法
- 内点法
- 风险等级: 🟢低（资源配置标配）

**✓ 整数规划 (Integer Programming)**
- 分支界限法
- 割平面法
- 风险等级: 🟢低（离散优化标配）

**✓ 动态规划 (Dynamic Programming)**
- 风险等级: 🟢低（组合优化标配）

**✓ 贪心算法 (Greedy Algorithm)**
- 风险等级: 🟢低（近似求解）

---

### 评价决策类

**✓ 层次分析法 (AHP)**
- 用于多准则决策
- 风险等级: 🟢低（评价问题标配）

**✓ TOPSIS 方法**
- 用于排序决策
- 风险等级: 🟢低（评价问题标配）

**✓ 熵权法 (Entropy Weight Method)**
- 用于权重确定
- 风险等级: 🟢低（评价问题标配）

**✓ 模糊综合评价**
- 用于定性转定量
- 风险等级: 🟢低（评价问题常见）

---

### 自定义模型（有明确的问题驱动）

**✓ 基于几何约束的特殊曲线**
- 例：两段圆弧S形曲线（满足长度恒定约束）
- 例：等距螺线参数化（螺距恒定）
- 风险等级: 🟢低（有明确的推导过程）

**✓ 基于物理过程的动力学方程**
- 例：碰撞检测的几何判定函数
- 例：运动约束下的参数关系
- 风险等级: 🟢低（推导清晰可复现）

## ⚠️ AI高频但不适合数学建模的模型

### 深度学习类（❌ 直接判为高风险）

| 模型 | AI为什么爱用 | 数模为什么不用 | 风险等级 |
|---|---|---|---|
| **深度神经网络 (DNN)** | 听起来很高级 | 数据少、过拟合、黑箱无可解释性 | 🔴高 |
| **卷积神经网络 (CNN)** | 图像处理明星 | 数模竞赛很少有图像问题 | 🔴高 |
| **循环神经网络 (RNN)** | 序列处理明星 | ARIMA已足够，RNN容易过拟合 | 🔴高 |
| **LSTM** | 长期依赖学习 | 时间序列通常10-100个点，ARIMA更合适 | 🔴高 |
| **强化学习 (RL)** | 智能决策听起来很酷 | 本题不是策略学习问题，搞复杂了 | 🔴高 |

### 启发式算法类（⚠️ 需谨慎）

| 算法 | AI为什么爱用 | 在数模中的问题 | 风险等级 |
|---|---|---|---|
| **遗传算法 (GA)** | 自然启发、名字新颖 | 比二分搜索复杂10倍，结果不一定更优 | 🔴高 |
| **蚁群算法 (ACO)** | 自然启发、名字新颖 | 同上，还要调多个参数 | 🔴高 |
| **粒子群优化 (PSO)** | 自然启发、名字新颖 | 同上 | 🔴高 |
| **模拟退火 (SA)** | 物理启发 | 可用，但通常二分搜索更直接 | 🟡中 |
| **禁忌搜索 (TS)** | 高级优化 | 过度工程化 | 🟠中 |

### 机器学习类（⚠️ 数据量有限时不适合）

| 算法 | 在数模中的问题 | 风险等级 |
|---|---|---|
| **支持向量机 (SVM)** | 高维问题才有用，竞赛题通常3-10维 | 🟠中 |
| **随机森林 (Random Forest)** | 数据量不足（通常<1000），容易过拟合 | 🟠中 |
| **XGBoost** | 同上，而且参数多难调 | 🟠中 |
| **朴素贝叶斯** | 可用，但通常逻辑回归更简单 | 🟡中低 |

### 概率统计类（⚠️ 一般不需要）

| 算法 | 在数模中的问题 | 风险等级 |
|---|---|---|
| **贝叶斯网络** | 因果关系链不明确 | 🟠中 |
| **马尔可夫链 (MC)** | 转移概率难估计 | 🟠中 |
| **隐马尔可夫模型 (HMM)** | 复杂度高，通常无需 | 🟠中 |

|---|---|---|

## 💡 判定规则

### 快速风险判定

```
你的论文用了以下模型吗？

✓ 用了：线性回归、ARIMA、K-means、SAT、二分搜索、AHP
  → 🟢低风险（标准竞赛工具）

✓ 用了：微分方程、动态规划、线性规划、SIR模型
  → 🟢低风险（学术工具，但要有明确的问题驱动）

✓ 用了：遗传算法、蚁群算法、粒子群
  → 🟠中风险（AI倾向，但如果论证清楚"为什么不用二分搜索"可接受）

✗ 用了：深度学习、CNN、LSTM、强化学习
  → 🔴高风险（AI高频，数模竞赛不需要）
```

## 📋 对标清单（自检用）

逐项检查你的论文中的每个模型：

- [ ] 这个模型的名称是否清晰？（如果模糊，是"AI样板"）
- [ ] 这个模型是否在数模竞赛中常见？（查上面的常用库）
- [ ] 这个模型的选择理由是否说明了"本题的特殊性"？
- [ ] 这个模型相比替代方案的收益有多大？（定量说明）
- [ ] 这个模型的参数是否都有来源说明？（不是"取值""假设"）
- [ ] 这个模型是否有代码实现和结果验证？（可复现）

如果有一项"否"，需要改进。如果模型本身就是"AI高频"，则直接判为高风险。
