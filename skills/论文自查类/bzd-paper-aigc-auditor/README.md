# BZD数学建模论文AI痕迹审计工具 v2.0

## 📋 项目概述

**bzd-paper-aigc-auditor** 是一个专为数学建模竞赛论文设计的AIGC审计工具，采用**两层递进式检查**方法，识别论文中的AI生成痕迹。

### 核心特点

- ✅ **两层递进设计**：语言特征扫描 → 建模逻辑深度审查
- ✅ **数模特化**：对标竞赛常用模型库，直击"高大上"模型陷阱
- ✅ **融合Humanizer-zh**：采用业界认可的中文AI文本检测方法
- ✅ **分层输出**：学生自检版 / 老师评审版 / 完整审计版
- ✅ **可操作化**：每个判定都有具体的改进建议

### 适用场景

| 用户 | 场景 | 输出版本 |
|---|---|---|
| 参赛学生 | 论文提交前自检 | 简洁自检版（问题定位+优先级） |
| 指导老师 | 论文评审快速判定 | 简洁版+完整版对照 |
| 赛事评委 | 论文深度审查存档 | 完整审查版（逐部分详细分析） |
| 社团运营 | 批量论文质量评估 | 简洁版快速筛选 |

## 🎯 核心概念

### 第一层：语言模板化扫描（权重60%）

重点检查**论文的表达特征**是否有AI痕迹：

```
检查项 = 高频连接词 + 排比句 + 被动句 + 拔高词
```

**为什么权重这么高？** 
AI生成的论文在语言层面有最明显的特征，容易被自动化检测。

**参考资源**：
- `humanizer-keywords.txt` — 所有高频词列表
- `BZD数模论文AI痕迹自查指南.html` — 学生自检版的"高频陷阱对照表"

### 第二层：数学建模逻辑审查（权重40%）

重点检查**建模的合理性**，识别AI倾向的复杂模型和自证式论证：

```
检查项 = 模型常用性 + 复杂度vs收益 + 华而不实特征 + 三问法
```

**为什么是这四项？**
- 模型常用性：检查是否用了AI高频的"高大上"模型（深度学习、强化学习等）
- 复杂度评估：检查是否过度工程化（用复杂模型解决简单问题）
- 华而不实：识别AI常见的五大虚浮特征
- 三问法：强制论证"问题→数据特征→替代方案"的完整链条

**参考资源**：
- `models-zh.md` — 常用模型库 vs AI高频模型对照
- `patterns-zh.md` — AI常见自证式论证模式库
- `audit-framework.md` — 第二层的详细评分标准

## 📊 评分体系

### 最终评分公式

```
最终AI风险分 = (第一层得分 + 第二层得分) / 2

范围：0-100
```

### 风险等级划分

| 分数 | 等级 | 含义 | 建议 |
|---|---|---|---|
| 0-20 | 🟢低 | 语言规范、建模清晰、模型合理 | 可直接接收 |
| 21-35 | 🟡中低 | 语言有套话、建模基本清晰 | 可接收，建议改进 |
| 36-54 | 🟠中 | 语言和建模均有问题 | 需深度检查 |
| 55-74 | 🔴中高 | 多维度问题，可能涉及AI | 强烈建议拒稿或改稿 |
| 75-100 | ⛔高 | 确认有AI拼装迹象 | 建议拒稿 |

### 置信度说明

- **仅论文**：置信度 = 中（±8-12分）
- **论文+赛题**：置信度 = 中（±6-10分）
- **论文+赛题+代码/结果**：置信度 = 高（±5-8分）

## 💡 核心原理

### 为什么这个框架有效

1. **两层递进**：先快速筛选（语言特征），再深度分析（建模逻辑）
2. **中文特化**：融合Humanizer-zh的连接词分析
3. **数模特化**：对标竞赛常用模型，直击AI的"复杂模型"陷阱
4. **量化判定**：每个风险都有具体的阈值和证据

### 为什么语言权重这么高（60%）

数学建模竞赛的特殊性：
- **篇幅短**：3-5万字，参赛队倾向于用最精炼的语言
- **规范性强**：大多数论文用类似的结构（问题分析→建立模型→求解→检验）
- **AI最明显**：AI生成的论文在语言层面有最明显的特征

因此，**语言特征的权重更高**。

### 为什么模型合理性这么重要（第二层40%）

数学建模竞赛的本质：
> **用最简洁、最有效的模型解决问题，而不是追求高深复杂**

AI的典型特征：
> **用看起来很"高大上"的复杂模型，但不一定适合问题**

因此，**识别"华而不实"的模型选择**是判定AI拼装的关键。

## 📖 使用指南

### 对于学生

#### 第1步：自检（5分钟）

打开 `BZD数模论文AI痕迹自查指南.html`，回答5个关键问题：

```
Q1：高频连接词是否过多？
Q2：是否有排比句后面直接跟模糊评价？
Q3：模型选择中是否说明了"为什么适合本题"？
Q4：每个参数都能追溯来源吗？
Q5：问间对接是否有明确的数据流说明？
```

五个都勾上？✅ 你的论文很好，可以提交。

有3个以上没勾上？⚠️ 需要进入第2步。

#### 第2步：对照修改（30分钟）

参考"高频陷阱对照表"和"最易得分的改进Top 3"修改论文：

```
陷阱1：连接词堆砌
  → 删除或在后面补充具体数据

陷阱2：拔高词无据
  → 改为有量化数据的表述

陷阱3：模型选择论证不明
  → 补充"因为本题的XX特性，所以选YY"的句子

陷阱4：参数来源不明
  → 建立"参数溯源表"，标注每个参数的来源

陷阱5：问间对接不明确
  → 补充"Q_i的ZZZ用于Q_i+1的YYY"的过渡句
```

#### 第3步：深度审计（可选）

修改完毕后，可以调用本skill的完整版进行深度审计：

```
用"学生自检版"快速了解主要问题
用"完整审计版"获得详细的改进建议
```

### 对于指导老师

#### 收卷后评审（5分钟/篇）

调用本skill，在"老师评审版"中快速查看：

```
语言模板化评分 [X]/100 + 其他四维评分 [Y]/100
  → 第一层总分

模型常用性 + 三问法通过率
  → 第二层总分

最终评分 = （第一层 + 第二层）/ 2 = [Z]/100
```

**评分意义**：
- <20 分：正常论文，可按常规评分
- 20-35 分：有改进空间，但建模清晰，可接收
- 35-54 分：需深度检查，问题较多
- 55+ 分：强烈建议拒稿或强制改稿

### 对于赛事评委

#### 深度审查（20分钟/篇）

调用本skill的"完整审计版"：

```
第一层五维评分表 → 了解论文的全景
第二层建模逻辑审查 → 核心建模是否合理
最优先修改的五项 → 论文的主要弱点
```

**存档**此报告供后续比较和研究。

## ⚠️ 重要声明

### 这个工具的限制

1. **不是身份鉴定**：评分不表示AI生成概率，仅评估论文的AI风格和未经人工核验的风险
2. **不替代正式检测**：不能替代知网、Turnitin等商业AIGC检测服务
3. **不是终极判定**：这个工具是辅助性的，最终判定还需要人工审查
4. **数模特化**：仅针对数学建模竞赛设计，不适用于其他学科

### 这个工具的优势

1. **规则透明**：每个评分都有具体的证据和判定标准，不是黑箱
2. **改进方向清晰**：不仅指出问题，还给出具体的改进建议
3. **量化判定**：用具体的密度、次数、公式而非模糊的"感觉"
4. **可复现**：同一篇论文、同一个标准，任何人都能得出相似的评分

## 📞 使用支持

### 常见问题

**Q1：评分不高是不是说明我的论文是AI生成的？**

A：不一定。评分反映的是"论文呈现出的AI风格"，可能因为：
- 语言不够精炼（连接词过多、拔高词无据）
- 建模论证不够清晰（没有说明"为什么"）
- 问间对接不够明确（没有明确的数据流）

这些都可以通过修改文字来改善，不一定是AI生成。

**Q2：我该信任评分还是信任我的直觉？**

A：结合两者：
- 如果评分低但直觉感觉论文很好 → 按照改进建议调整文字，重新评分
- 如果评分高但直觉感觉论文很好 → 深度阅读"最优先修改的五项"，看看是否有遗漏

**Q3：什么样的改进是有效的？**

A：有效的改进必须：
- 保留原有的事实和数学含义（不虚构数据）
- 补充"本题的特殊性"说明（说明为什么选这个模型）
- 量化所有声称（用数字替代"高""强""好"）
- 追踪参数来源（说明每个参数从哪来）

无效的改进（虽然能降低评分但不推荐）：
- 删除高频连接词但不补充实质内容
- 为了降分而故意写错别字或病句
- 虚构数据或过程
