# 第一层快速检查卡（2分钟快速判定）

## 🚀 快速筛选模式 - 5分钟内快速判定风险等级

### Step 1: 语言特征快速扫描（2分钟）

**高频连接词密度**
```
操作：Ctrl+F 搜索 "综上所述" "此外" "进一步" "与此同时" "显然"
计算：出现总次数 / 全文总句数
判定：
  <15%    🟢 安全
  15-20%  🟡 轻微
  20-25%  🟠 警戒
  >25%    🔴 危险
```

**被动句占比**
```
操作：抽取3段(开头、中段、末尾)，数一数被动句
正常范围：15-20%
判定：
  >30%    🔴 严重
  25-30%  🟠 警戒
  15-25%  🟢 安全
```

**拔高词检查**
```
操作：Ctrl+F 搜索 "显著" "精度高" "优势明显" "高效"
每个拔高词后是否有具体数字或对比？
判定：
  无数据的拔高词>5个      🔴 危险
  3-5个无数据拔高词      🟠 警戒
  <3个或都有数据          🟢 安全
```

**TTR词汇多样性**（可选，需统计工具）
```
不同词数 / 总词数
目标：>0.5（正常）
<0.4 = 词汇严重重复 🔴
```

### Step 2: 事实层快速验证（2分钟）

**引文spot check**
```
抽查3篇"关键文献"（出现>2次的文献）
Google Scholar快速搜索：能找到吗？
判定：
  全部找到          🟢 安全
  1篇找不到         🟠 警戒
  2篇以上找不到     🔴 虚构风险
```

**参数一致性**
```
列出3个关键参数（如p=0.55m, v=1m/s, Δt=0.5s）
在全文中追踪，是否始终一致？
判定：
  完全一致          🟢 安全
  轻微波动(±1%)     🟡 正常
  明显矛盾(>5%)     🔴 危险
```

**术语统一性**
```
核心算法名称是否始终一致？
例：遗传算法GA是否一直叫GA，还是有时变成"进化策略""种群搜索"？
判定：
  统一使用          🟢 安全
  有变体但不混淆    🟡 可接受
  多个名字混用      🔴 混乱
```

## 🔍 发现问题时的快速定位

### 如果高频连接词>25%

```
快速修改：
□ 在摘要中查找"综上所述" - 每章最多1次
□ 在问题分析中查找"进一步" - 删除重复
□ 全文查找"此外" - 删除冗余的
```

### 如果被动句占比>30%

```
快速修改：
将 "该模型被应用于..." 改为 "我们应用该模型..."
将 "结果被验证..." 改为 "我们验证了结果..."
```

### 如果拔高词多于5个且无数据

```
快速修改：
"显著提升" → "精度从A提升至B，提升X%"
"高效" → "耗时0.5s，相比基准快10倍"
"有效" → "准确率99.2%（基准89.5%）"
```

### 如果引文找不到

```
紧急操作：
1. 再次在Google Scholar搜索一遍
2. 检查是否打错了年份或作者名
3. 如果确实找不到，该文献可能虚构 ⚠️ 必须删除或核实
```

### 如果参数不一致

```
快速查找：
1. 在全文Ctrl+F搜索该参数值
2. 对比每个出现位置的数字
3. 如发现矛盾（p=0.55 vs p=0.54），标记为"计算错误"或"虚构"
```

### 如果术语混乱

```
快速统一：
选择一个标准术语名（如"直升机"）
全文Ctrl+H替换其他变体（"直升""直升机"）
建立术语表，确保全文一致
```

## 💡 使用建议

**场景1：参赛队快速自检**
- 用这个卡片做5分钟快速评估
- 如果得分<60，立即按"快速定位"部分修改
- 修改后重新快速检查，确保>60再进第二层

**场景2：指导老师快速审阅**
- 用这个卡片在5分钟内快速判定是否需要深度检查
- 高风险指标（<40）直接给学生改进建议
- 中等风险（40-60）进入第二阶段或给改进清单

**场景3：评委快速初筛**
- 用这个卡片在5分钟内快速筛选"明显异常"的论文
- 如果<40分，做出"疑似AI生成"的初步判定
- 否则进入第二层或综合评审
