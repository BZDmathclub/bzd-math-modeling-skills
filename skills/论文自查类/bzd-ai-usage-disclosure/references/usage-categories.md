# AI 使用用途分类与核验观察点

仅用于帮助归类用户已经确认的真实用途，不用于推断使用历史。

| 用途方向 | 具体用途示例 | 需要说明的核验 |
|---|---|---|
| 资料辅助 | 检索关键词、检索式、公开资料查找、已有文献整理 | 文献和来源真实可查，引用与原文一致 |
| 赛题理解 | 条件梳理、小问关系、输入输出与约束识别 | 对照原题逐句核对，没有遗漏或改写条件 |
| 建模讨论 | 候选模型、适用条件比较、假设检查、求解思路 | 参赛队完成选型、推导和适用性判断 |
| 数据处理 | 字段梳理、数据质量、缺失异常方法、标准化与特征建议 | 处理代码、前后样本量、参数与结果可复核 |
| 程序辅助 | 框架建议、局部代码生成、调试、报错分析、效率优化 | 逐行检查、实际运行、样例测试与结果核对 |
| 模型检验 | 指标、残差、灵敏度、稳健性方案 | 检验真实执行，参数范围和结论有依据 |
| 结果核验 | 数量级、单位、程序输出与图表、摘要结论一致性 | 说明核对范围、差异和最终修改 |
| 图表辅助 | 图表类型、绘图代码、流程图、格式检查 | 数据来自真实计算，单位标签与正文一致 |
| 写作辅助 | 标题、摘要、关键词、重述、分析、评价、润色、翻译 | 技术含义、数字、单位、模型和结论未改变 |
| 格式检查 | 编号、符号单位、参考文献与全文格式 | 以当年官方格式为准，人工确认最终稿 |
| 支撑材料 | 文件分类、命名、程序结果对应、AI披露整理 | 最终提交清单人工复核，不编造记录 |
