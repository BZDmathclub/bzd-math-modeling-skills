# 模型假设审查规则

## 合格假设的核心标准

一条假设应尽量包含“假设内容＋依据＋建模作用”。判断重点是：

- **相关**：直接服务于赛题或后续模型；
- **必要**：没有它，模型边界、变量关系或求解条件会不清楚；
- **合理**：不违背题意、常识、数据和问题机制；
- **适度**：只忽略次要因素，不删除核心矛盾；
- **可解释**：能够说明简化对象和潜在影响；
- **可追踪**：后文能找到对应的变量、参数、公式、约束、检验或局限。

## 假设来源

- **题目明确给出**：准确保留题目规定的数值、状态、范围与条件，不得擅自修改。
- **由题意合理推出**：应能从研究范围、正常运行情境、附件信息或基本常识推出，不能只以“方便建模”为理由。
- **具体模型所需**：线性、独立、平稳、正态、泊松、均匀混合、参数恒定等条件应由数据检验、机理分析、领域常识、题目条件或可靠文献支持。

## 常见类型与核对点

| 类型 | 应核对的重点 | 后文对应 |
|---|---|---|
| 数据可用性 | 是否承认误差；是否与清洗过程一致 | 数据来源、清洗与误差说明 |
| 极端事件排除 | 是否确会改变机制；是否只是套话 | 适用范围与局限 |
| 忽略次要因素 | 被忽略因素是否真的次要 | 变量选择与模型边界 |
| 参数稳定 | 明确哪个参数、何种范围、哪个周期 | 常数参数与适用期限 |
| 对象理想化 | 是否破坏题目研究的关键特征 | 几何、物理或群体模型 |
| 分布形式 | 是否有检验、机理或文献依据 | 参数估计与拟合检验 |
| 变量关系 | 线性、可加等关系是否合理 | 目标函数和约束形式 |
| 行为决策 | 是否符合情境；是否过度完全理性 | 决策规则或目标函数 |
| 时空尺度 | 时间步长、空间均匀性、统计口径 | 离散化与区域模型 |
| 独立性 | 是否存在竞争、冲突、传染或共同驱动 | 概率或回归模型条件 |

## 严重风险

### 循环论证

“模型能够准确预测”“指标体系全面合理”“结果必然有效”等属于需要验证的结论，不能作为假设。

### 删除核心因素

题目要求研究政策，就不能统一假设政策不变；研究拥堵，不能忽略拥堵；研究随机波动，不能把过程完全确定化；研究对象间作用，不能无依据假设彼此独立。

### 数据绝对正确

“不存在任何缺失、异常或错误”通常过强，也可能与正文的数据清洗矛盾。较合理的表述是：经过核验和清洗后保留的数据满足建模需要，误差不会改变总体规律。

### 无依据强假设

正态、泊松、平稳、独立、线性、均匀混合、完全理性等假设必须有依据。证据不足时，应改为待检验条件、局部近似、情景假设，或采用更稳健的模型。

## 章节错位

插值补全、Z-score识别异常、标准化、采用某算法求解、计算相关系数或误差，属于数据处理或模型求解，不是模型假设。可以写成假设的是这些操作赖以成立的条件，例如“相邻观测期变化平稳，因此插值不会造成明显系统偏差”。

## 集合层面检查

- 是否覆盖题目明确条件和模型关键前提；
- 是否有多条同义的数据可靠性假设；
- 是否存在相互冲突的稳定性、独立性或数据完整性表述；
- 是否把多个问题或模型的条件混在一起，导致适用范围不清；
- 是否需要注明“仅适用于问题X”或“仅适用于基准情景”；
- 是否在模型检验与局限分析中回应强假设。

假设通常为4—8条，但不是评分硬指标。简单问题3—5条可能足够，复杂问题可以超过8条。优先删除重复、无用途和纯套话。

## 修改建议的尺度

- **删除**：循环论证、纯套话、重复或完全无用途；
- **改写**：方向合理但过强、范围不明或缺少作用说明；
- **补证**：分布、独立、线性、平稳等需检验或文献支持；
- **限定**：注明适用问题、时间、空间或情景；
- **移位**：把数据处理和算法步骤移到相应章节；
- **补充**：仅在赛题明确条件或后续模型确实需要时提出候选假设。
