# 问题重述生成规范

## 章节职责

问题重述回答“题目要求做什么”。它应以独立、准确、简洁的语言呈现研究背景、关键条件和全部任务，为后续问题分析建立事实边界。

推荐结构：

1. 研究背景；
2. 问题回顾；
3. 研究综述。

## 研究背景

背景应围绕：

- 研究对象及基本属性；
- 与赛题任务直接相关的现实情境；
- 当前的主要现象、困难或矛盾；
- 研究该问题的现实价值。

通常写1—3段。避免扩展与建模任务无关的行业历史、政策沿革和百科知识，也不要在背景中预先宣布将使用什么模型。

## 问题回顾

必须准确保留：

- 研究对象；
- 关键数据和已知条件；
- 时间范围、单位和样本规模；
- 约束条件；
- 每一问要求识别、分析、预测、评价、比较、优化或设计的内容；
- 指定的结果形式、文件形式或文体要求；
- 附件在各任务中的真实作用。

允许调整语序、合并重复条件、删除非必要情境描述，并把叙述性要求转换为明确任务。不得为了“降重”改变题意、遗漏限定条件或扩大任务范围。

## 研究综述

建议约500字、3—4段，依次说明：

1. 总体研究现状和主要方向；
2. 一类主要方法及适用任务；
3. 另一类主要方法及适用任务；
4. 现有不足和本文可能的建模切入点。

综述需要与赛题对象和任务相关。具体作者、论文、期刊、年份、数据与结论必须真实可核验。没有可靠来源时，只能概述方法方向并明确提出待核验文献。

## 内容边界

问题重述通常不写：

- 最终选择的模型；
- 具体算法和软件；
- 指标筛选理由；
- 变量关系分析；
- 数据清洗与求解过程；
- 公式推导；
- 计算结果和最终结论。

研究背景和问题回顾通常占半页至一页；加入综述后，全章通常控制在1—2页，赛事另有规定时以官方要求为准。
