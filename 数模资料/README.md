## 三、使用说明

- 模板和说明材料仅供写作、训练与自查参考，不代表竞赛官方统一模板；
- 涉及竞赛规则、AI 工具披露、论文页数和支撑材料要求时，以当届组委会及赛区最新正式文件为准；
- 使用模板后仍需根据具体赛题、真实模型、代码和结果进行修改，不应直接保留示例内容；
- 参考文献、数据来源、程序结果和 AI 使用记录必须真实，不得根据模板虚构；
- 公开提交前应清除姓名、学校、指导教师、赛区、队号、联系方式、本地绝对路径和文档作者元数据。

## 四、收录原则

- 仅收录公开资料、自主整理内容或已获得传播授权的材料；
- 不上传未公开赛题、未公开参赛论文或包含个人身份信息的文件；
- 不上传 API Key、Token、账号密码及其他敏感内容；
- 新增或替换文件时，应同步更新本索引中的文件名称、用途和适用范围。
