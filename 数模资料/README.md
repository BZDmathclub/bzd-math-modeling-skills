# 数模资料

本目录用于逐步整理可公开传播的数学建模备赛资料，计划包括：

- 常用 AI 提示词；
- 数学建模论文模板；
- 国赛评阅要点示例与参考资料；
- 其他具有明确传播授权的备赛材料。

## 收录原则

- 仅收录公开资料、自主整理内容或已获得传播授权的材料；
- 不上传未公开赛题、参赛论文、内部评阅文件或包含个人身份信息的文件；
- 不上传 API Key、Token、账号信息及其他敏感内容；
- 资料涉及年份或竞赛规则时，应标注适用年份，并提醒使用者以当届官方规则为准；
- 新增文件时，应在本页补充文件名称、用途、来源和适用范围。
