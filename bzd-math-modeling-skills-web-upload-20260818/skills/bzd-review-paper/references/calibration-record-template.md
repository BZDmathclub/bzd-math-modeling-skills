# Official Calibration Record Template

Create one record per contest/year/problem or one clearly scoped general rule set. Store only user-supplied or verifiable official material.

```markdown
# <Contest> <Year> <Problem/Scope>

## Metadata
- Contest:
- Year:
- Division/track:
- Problem ID and title:
- Applies to:
- Source name/file/link:
- Source authority: official / organizer clarification / historical reviewer material
- Date ingested:

## Source-preserved requirements
| Source location | Requirement or scoring instruction | Mandatory? |
|---|---|---|

## Normalized scoring rules
| Rule ID | Problem task | Category | Observable evidence | Points/weight/cap | Explicit/inferred | Confidence |
|---|---|---|---|---:|---|---|

## Weight rationale
| Rule ID | Centrality | Difficulty/workload | Dependency | Official emphasis | Rationale |
|---|---|---|---|---|---|

## Award or score calibration
- Eligible population:
- Sample size:
- Score distribution or cutoffs:
- Award rates:
- Screening/finalist bias:

## Derived patterns
List only cautious conditional inferences. State supporting records, number of cases, scope, confidence, and exceptions.

## Conflicts and unresolved ambiguity
Record conflicts; never silently reconcile incompatible official sources.
```

When new material arrives, compare it with existing records. Update a general rule only when its scope is justified by multiple compatible official records. Retain problem-specific exceptions.
