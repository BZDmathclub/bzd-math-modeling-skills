# Historical Review Signals

These signals were distilled from 2020-2025 CUMCM review material and calibrated cases. They are detection aids, not substitutes for current wording.

| Prompt wording | What it usually signals | What must not be lost |
|---|---|---|
| `分析……相关特性/影响` | dependence, mechanism, uncertainty, or interaction | data structure, significance/effect size, competing factors |
| `给出相应的关系模型` | explicit relation with variables and parameters | formulation, estimation, diagnostics |
| `最佳/最优/最大/最小` | objective, variables, feasible set, credible search | constraints, boundary/global checks, feasibility |
| `合理分组` | operational, interpretable, exhaustive groups | thresholds, coverage, separation, sensitivity |
| `综合考虑` | coupled model rather than disconnected analyses | how factors enter one model and trade-offs |
| `分析误差/可靠性/敏感性` | independent validation route | error source, propagation, stability |
| `进一步/在前问基础上` | inheritance plus genuine extension | reused output and new mechanism/constraint |
| `分别` | scenario-specific comparable results | no silent pooling; consistent units/metrics |
| `附件给出` | data provenance, fields, repeated entities | row/subject identity, missingness, restrictions |
| `填入附件/表格` | separately judged deliverable | exact rows, columns, units, order, precision |
| `不考虑/忽略/假设` | authorized simplification and boundary | exclude only authorized effects |
| shape/direction language | physical acceptance predicate | full geometry, not an unjustified point surrogate |
| repeated records | dependence or recursion | entity grouping and leakage-free validation |
| multiple stages/years/rounds | state propagation | balance, recursion, transition legality |

## Historically costly missed links

- Foundational physics/state models feed every later optimization; an invalid simulator invalidates plausible optima.
- A later precision question often adds named corrections, new parameters, and reconstruction, not just decimals.
- Groups must be usable on new cases; gaps, overlap, or future-outcome-defined groups are not operational.
- A predictor used in optimization carries its valid domain, uncertainty, and leakage risks downstream.
- Repeated measurements of one entity must not be treated as independent or split carelessly.
- Multi-period/rework tasks require state, probability, and material balance.
- Physical target shapes cannot automatically be reduced to center points.
- Information restrictions define observability and forbid unavailable coordinates, identities, future data, or external sources.
- Required spreadsheets, labels, units, and precision are substantive outputs.

## Problem-family checks

- Dynamics/control: frame, force/state equations, transient/steady state, energy balance, bounds.
- Inverse/measurement: parameter variability, identifiability, multi-condition consistency, forward reconstruction.
- Statistics/biomedicine: repeated measures, response support, missing/failure mechanism, threshold cost.
- Planning/operations: hard constraints, recursion, accounting denominator, feasibility before profit.
- Geometry/coverage: coordinates, shapes, boundaries, union, resolution convergence.
- Machine learning: label, entity grouping, leakage-free split, imbalance, calibration, required outputs.
